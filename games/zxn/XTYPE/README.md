# X-TYPE

A horizontal shoot-'em-up for the ZX Spectrum Next, written in NTC BASIC (only the little things that need it are inline
assembler). An original game in the spirit of the classic pod-and-beam shooters: new ship, new orb, new enemies,
new stages, new sound. No arcade ROM, art or data is used.

(c) 2026 Cyborg Unicorn Pty Ltd

## Play

Run `build/XTYPE.NEX` on a Next (or an emulator that does the Next's tilemap and 4-bit sprites).

| key | does |
|---|---|
| Q A O P | up, down, left, right (Kempston joystick 1 works too) |
| SPACE | tap: shoot. Hold: charge the wave beam (the gauge at the bottom right); let go to fire it |
| Z | the orb: send it out, call it back; with the orb behind you, swap it to the front |

Pick-ups (dropped by the red carriers): **S** speed (3 levels), **P** power (single, double, spread), **O** the orb.
The orb is indestructible, hurts what it touches, stops enemy bullets and shoots with you (forwards in front, backwards behind).
A hit loses your pick-ups and sends you back to the last checkpoint. Three lives. Two stages, each with a mid-boss and a
boss; then it all starts again, tougher (more hit points, faster bullets).

## How it is built

- The tilemap carries the terrain: the hardware scrolls it a pixel a frame and a new column of tiles is written every 8
  pixels into the cell just left of the screen. The tilemap is clipped to 312 pixels so the wrap-around cell never shows.
- The 128 hardware sprites carry everything else (ship, orb, shots, the wave, enemies, bosses, explosions, the HUD).
- Stages (terrain heights per column, enemy waves, checkpoints) are generated by `tools/stages.py` into `Stages.cls`.
- All the art is drawn in `tools/art.py` (-> `GfxData.cls`, `Pals.cls`, `build/XTYPE.DAT`, previews in `gfx/`).
- ByRef is NTC's default, so parameters are passed by reference throughout.

## Build

```
python3 tools/art.py          # sprites, tiles, palettes
python3 tools/stages.py       # the stages
node build.js /path/to/ntc/src   # needs sjasmplus on the PATH
```

## Tested

In an emulator only (`test/nextemu.py`, Python): the title, both stages, both bosses and mid-bosses, the beam, the orb,
death and checkpoints, game over. `test/bot.py` flies the ship by script; across 9000 frames the game kept pace with
every emulated frame. Not tried on a real Next: sound (the AY effects) and the feel of the controls are unchecked.
