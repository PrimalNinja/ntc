S3D Make

Turns an OSM Cut file (NAME-cut.txt.gz, or its parts) into the data file a STATE3D program (AUCKLAND.BIN) flies through: AUCKLAND.DAT, 16K blocks for the CPC's expansion RAM. Everything runs in this page.

1. The OSM Cut file (all its parts, if it was split)
2. The data

3968K: 248 blocks of 16K, for a 4MB CPC (the program and the screens need the rest). Smaller: the smallest buildings and the minor roads go first.
