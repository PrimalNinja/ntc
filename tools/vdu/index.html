Writing to a screen

Any program that can make an HTTP GET (a CPC through CyborgOS's NET, a PC, a script):
vdu.php?a=put&s=ID&k=KEY&c=PRINT%20Hello        (several lines: %0A between them)
vdu.php?a=get&s=ID&n=POINTER                      (0: from the start - a replay; -1: live)
vdu.php?a=events&s=ID&k=KEY&n=POINTER            (taps in its touch zones, keys)
Commands: MODE n, CLS, PRINT text[;], LOCATE x y, PEN i, PAPER i, INK i c, BORDER c, WINDOW l r t b, STREAM n, TITLE text, ORIGIN x y, MOVE x y, DRAW x y, PLOT x y, GPEN i, CLG [i], BOX x y w h, FILL x y w h, CIRCLE x y r, ZONE name x y w h, ZONE OFF. The whole of it: README.md.
