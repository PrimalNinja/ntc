# 10.7 Text and records in nodes

*10 The List library*

A node's data is plain bytes: it can hold text, a Type, a block of graphics - anything. There
are no string methods in `List` yet; copy the bytes in and out with `Memory.Copy(from, to,
length)`, using `List.Data(node)` as one end and `VarPtr` of a variable as the other.

```basic
Const NAMEF = 0, SCORE = 13          ' a name: 12 characters and its 0 byte; then a word
Dim h As Long, n As Long, r As Integer, s As String Max 12
h = List.Create(15)
AddPlayer "Alice", 950
AddPlayer "Maximilianus Rex", 720
n = List.First(h)
Do While n <> 0
  r = Memory.Copy(List.Data(n) + NAMEF, Near(VarPtr(s)), 13)
  Print s; " "; List.GetWord(n, SCORE)
  n = List.NextOf(n)
Loop
r = List.Destroy(h)

Sub AddPlayer(nm As String, sc As Integer)
  s = Left$(nm, 12)
  n = List.Append(h)
  r = Memory.Copy(Near(VarPtr(s)), List.Data(n) + NAMEF, Len(s) + 1)
  List.SetWord n, SCORE, sc
End Sub

Function Near(a As Integer) As Long    ' a main memory address as a far pointer
  Near = CLng(a) And &HFFFF&
End Function
```

```text
Alice 950
Maximilianus 720
```

- A String is its characters and a 0 byte; `VarPtr(s)` is the first character. Copy
  `Len(s) + 1` bytes in, so the 0 byte goes too; copying back, the 0 byte ends the text.
- Make the field one byte longer than the longest text, and cut the text to fit first
  (`Left$`), or the copy runs into the next field.
- `Memory.Copy` takes far pointers. `VarPtr` gives an Integer, and an address above `&7FFF` is
  negative, so `CLng` of it alone gives a wrong page. `CLng(a) And &HFFFF&` keeps the address
  and makes the page 0 (main memory): that is what `Near` does.
- Binary data (a sprite, a level map, a Type's fields) is copied the same way, any length up
  to the node's size.
