# 10.1 List: linked lists

*10 The List library*

The `List` class keeps linked lists in the Memory class's heap - RAM pages with
`CPCExpansion`, the free main RAM with `Small`. A list can be far bigger than the program's
own memory, and takes only 4 bytes of it (its handle).

| Member | Does | Page |
|---|---|---|
| `Create(size)`, `Destroy(h)`, `Count(h)` | a new list of nodes with *size* data bytes; gone; how many nodes | [10.2](10.2-making-a-list.md) |
| `Append(h)`, `Prepend(h)`, `InsertAfter(h, node)`, `Delete(h, node)` | add and remove nodes | [10.2](10.2-making-a-list.md), [10.4](10.4-insert-delete-search.md) |
| `First(h)`, `Last(h)`, `NextOf(node)`, `PrevOf(node)` | walk the list | [10.2](10.2-making-a-list.md) |
| `GetWord`, `GetByte`, `SetWord`, `SetByte`, `Data(node)` | a node's data | [10.3](10.3-node-data.md) |
| `Search(h, offset, value)`, `Sort(h, offset)` | find, sort | [10.4](10.4-insert-delete-search.md), [10.5](10.5-sorting.md) |

Every platform has it. How big a list can get:

| Machine | Room for 12 byte nodes (8 data bytes) |
|---|---|
| 64K CPC (`Small`), CP/M | what is left after the program, about 30-40K |
| 6128 (`CPCExpansion`) | 4 pages, 64K: about 5,000 |
| 512K expansion | about 32,000 (a list counts to 32,767) |
