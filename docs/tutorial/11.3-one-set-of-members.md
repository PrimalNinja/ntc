# 11.3 One set of members

*11 Classes*

In VB, `Dim a As New Counter` makes a new object with its own data. NTC makes no objects while
the program runs: a class has **one** set of members, and every variable `As New Counter`
names the same one.

<!-- file: Counter.cls -->
**Counter.cls**

```basic
Private mTotal As Integer
Public Sub Add(ByVal v As Integer)
  mTotal = mTotal + v
End Sub
Public Property Get Total() As Integer
  Total = mTotal
End Property
```

**Main.bas**

```basic
Dim a As New Counter, b As New Counter
a.Add 5
b.Add 7
Print a.Total; " "; b.Total; " "; Counter.Total
```

```text
12 12 12
```

A class that needs several copies of its data keeps them itself, in arrays, and takes a
number to say which:

<!-- file: Players.cls -->
**Players.cls**

```basic
Private mScore(3) As Integer
Public Sub Add(ByVal p As Integer, ByVal v As Integer)
  mScore(p) = mScore(p) + v
End Sub
Public Function Score(ByVal p As Integer) As Integer
  Score = mScore(p)
End Function
```

**Main.bas**

```basic
Players.Add 0, 5
Players.Add 1, 7
Print Players.Score(0); " "; Players.Score(1)
```

```text
5 7
```

No `Class_Initialize`, events or `Implements` either. In return a class costs nothing extra:
its members are plain variables and procedures.
