# 4.1 Flow control keywords

*4 Flow control*

How a program decides and repeats. Each has its own page.

| Keywords | Does | Page |
|---|---|---|
| `If ... Then ... ElseIf ... Else ... End If` | run code when something is true | [4.2](4.2-if.md) |
| `Select Case ... Case ... Case Else ... End Select` | pick one of several cases | [4.3](4.3-select-case.md) |
| `For ... To ... Step ... Next` | count | [4.4](4.4-for.md) |
| `For Each ... In ... Next` | each element of an array | [4.4](4.4-for.md) |
| `Do ... Loop`, with `While` / `Until` | repeat | [4.5](4.5-loops.md) |
| `While ... Wend` | repeat while true | [4.5](4.5-loops.md) |
| `Exit For / Do / While / Sub / Function` | leave now | [4.5](4.5-loops.md) |
| `GoTo`, `GoSub ... Return`, `On ... GoTo / GoSub` | jump to a label | [4.6](4.6-goto-and-gosub.md) |
| `Sub`, `Function`, `Call` | procedures | [4.7](4.7-subs-and-functions.md) |
| `End`, `Stop`, `Error`, `Debug.Assert` | end the program | [4.8](4.8-ending-and-checking.md) |
| `IIf(c, a, b)`, `Choose(n, a, b, ...)` | pick a value | [4.2](4.2-if.md) |

A true value is anything but 0. Compares give True (-1) or False (0).
