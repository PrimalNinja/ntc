# 14.4 A game loop in a Tick

*14 Interrupt handlers*

A game's logic can run in a `Tick` at a fixed 50 a second, whatever the drawing does: the main
loop draws as fast as it can, the `Tick` moves things.

<!-- file: Game.cls -->
**Game.cls**

```basic
Option Class Interrupt 50
Public X As Integer, Dx As Integer
Public Ready As Integer
Public Sub Tick()
  If Dx = 0 Then Dx = 1
  X = X + Dx
  If X >= 39 Or X <= 1 Then Dx = -Dx
  Ready = -1
End Sub
```

<!-- platform: cpc -->
**Main.bas**

```basic
Option Turbo Off
Dim shown As Integer
Game.X = 1
Do
  If Game.Ready Then
    Game.Ready = 0
    Locate shown, 10 : Print " ";
    shown = Game.X
    Locate shown, 10 : Print "*";
  End If
Loop Until Inkey <> 0
```

If the drawing reads several things the `Tick` changes, a `Tick` can come between two reads.
Keep two copies: the `Tick` writes one, and when it is done it says so (`Ready`); the main loop
copies them and draws from its copy. Then nothing is drawn half moved.

That is the end of the tutorial. The [user guide](../userguide.md) has every keyword in full,
and `src/bas/` has the examples.
