# 8.2 Loading and saving

*8 The FileSystem library*

`Save(name, address, length)` writes memory to a new file. `Load(name, address, maxlen)` reads
a file into memory and gives its length. Use `VarPtr` for the address of an array.

<!-- run: cpm -->
```basic
Dim hs(4) As Integer, back(4) As Integer, r As Integer, i As Integer
For i = 0 To 4 : hs(i) = (5 - i) * 100 : Next
r = FileSystem.Save("HISCORE.DAT", VarPtr(hs), 10)
Print "saved "; r
r = FileSystem.Load("HISCORE.DAT", VarPtr(back), 128)
Print "loaded "; r; " bytes, first "; back(0)
```

```text
saved 0
loaded 128 bytes, first 500
```

- CP/M keeps files as 128 byte records, so `Load` reads whole records: give it room for them
  (`maxlen`), or it stops with `TooBig`.
- On the CPC (`cpcfw`, `cpcmin`) the file is an AMSDOS binary: BASIC can `LOAD"HISCORE.DAT"`
  it too. Add `Option RomEnable 7`, or the file goes to tape after `RUN"`.
- `Load` straight into the screen, a RAM page or a reserved area is the quick way to bring in
  graphics or a level ([9.5](9.5-filling-a-page.md)).
