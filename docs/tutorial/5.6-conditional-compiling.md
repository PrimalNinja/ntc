# 5.6 Compiling parts of a program

*5 Options and compiler control*

`#If` compiles one part and skips the rest:

```basic
#If NTC_CPM Then
Print "CP/M"
#ElseIf NTC_TEST Then
Print "the test platform"
#Else
Print "a CPC"
#End If
```

```text
the test platform
```

The compiler defines:

| Name | When |
|---|---|
| `NTC` | always (VB doesn't have it, so `#If NTC` keeps VB and NTC code in one file) |
| `NTC_CPC`, `NTC_CPCMIN`, `NTC_CPCFW`, `NTC_CPM`, `NTC_TEST` | the platform |
| `NTC_MEM_SMALL`, `NTC_MEM_CPCEXPANSION` | the memory scheme ([5.4](5.4-memory-options.md)) |
| `NTC_TERM_VT52`, `NTC_TERM_ANSI`, `NTC_TERM_POS` | `Option Terminal` |

`#Const NAME = value` makes your own:

```basic
#Const DEBUGGING = 1
#If DEBUGGING Then
Print "debug build"
#End If
```

```text
debug build
```

Options work inside `#If` too - `bas/memmap.bas` reserves the window only on the CPC.
