# 8.5 Random access

*8 The FileSystem library*

`ForUpdate` opens a file for reading and writing anywhere (made if it isn't there). `Seek`
moves to a byte (a Long, 0 = the start); the next read or write happens there. Fixed size
records make it easy:

<!-- run: cpm -->
```basic
Const RECSIZE = 4
Dim rec(1) As Integer, h As Integer, r As Integer, i As Integer
h = FileSystem.Open("RECS.DAT", FileSystem.ForUpdate)
For i = 0 To 9
  rec(0) = i : rec(1) = i * i
  r = FileSystem.Seek(h, CLng(i) * RECSIZE)
  r = FileSystem.Write(h, VarPtr(rec), RECSIZE)
Next
r = FileSystem.Seek(h, 7 * RECSIZE)
r = FileSystem.Read(h, VarPtr(rec), RECSIZE)
Print "record 7: "; rec(0); " "; rec(1)
rec(1) = -1
r = FileSystem.Seek(h, 7 * RECSIZE)
r = FileSystem.Write(h, VarPtr(rec), RECSIZE)
r = FileSystem.Seek(h, 7 * RECSIZE)
r = FileSystem.Read(h, VarPtr(rec), RECSIZE)
Print "changed: "; rec(1)
r = FileSystem.Close(h)
```

```text
record 7: 7 49
changed: -1
```

CP/M only. A record number times the record size is the place: use `CLng` so a big file's
offset doesn't wrap round.
