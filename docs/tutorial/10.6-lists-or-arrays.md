# 10.6 Lists or arrays?

*10 The List library*

| | Array | List |
|---|---|---|
| Memory | its whole size, in the program's memory | 4 bytes in the program; the nodes in the heap (RAM pages on a 6128) |
| Size | fixed when compiling (`ReDim` up to the biggest one in the program) | grows and shrinks while running |
| Getting element *i* | quick: `a(i)` | walk from `First` |
| Adding / removing in the middle | move everything after it | change two links |
| Speed of one access | fast | a call (about 600 microseconds) |

Use an array for small, fixed tables you index a lot. Use a list for anything big, anything
whose size isn't known, and anything you add to and take from. On a 6128, a list can hold
several times what fits in the program's own memory - `Dim a(5000) As Integer` takes 10K of
it, a list of 5,000 nodes takes 4 bytes.
