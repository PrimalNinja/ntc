# 14.2 The Interrupt statement

*14 Interrupt handlers*

`Interrupt SubName` runs a Sub (no parameters) after interrupts, at the next safe point.
`Interrupt Off` stops it.

<!-- platform: cpc -->
```basic
Option Turbo Off
Dim beats As Integer, t As Integer
Interrupt Beat
t = Ticks
Do : Loop Until Ticks - t >= 300        ' a second
Interrupt Off
Print beats; " beats in a second"

Sub Beat()
  beats = beats + 1
End Sub
```

- When `Beat` returns it can run again: it runs about as often as interrupts come, while
  the program does its own thing.
- cpc, cpcmin and cpcfw (`System.HasHook`), normal mode only.
- For a Sub at a set rate, use an interrupt class ([14.3](14.3-interrupt-classes.md)).
