# 8.7 Devices and volumes

*8 The FileSystem library*

A **device** is how files travel: `TAPE` or `DISC`. A **volume** is a drive on the disc: `A`,
`B`, and whatever else the disc system has (`C` and `M` on an M4; `A` to `P` on CP/M).

<!-- run: cpm -->
```basic
Dim r As Integer
Print FileSystem.Devices(); " "; FileSystem.CurrentDevice()
r = FileSystem.SelectVolume("A")
Print "volume "; FileSystem.CurrentVolume(); ", known: "; FileSystem.Volumes()
```

```text
DISC DISC
volume A, known: A
```

| Method | Does |
|---|---|
| `Devices()` | `"TAPE,DISC"` (CPC with a disc system), `"TAPE"`, `"DISC"` (CP/M) |
| `SelectDevice(name)` | files go there from now on (CPC: like `|TAPE` / `|DISC`) |
| `SelectVolume(name)` | the drive for names without one |
| `Volumes()` | the volumes used so far |

Neither AMSDOS nor CP/M can list the drives there are, so `Volumes()` lists the ones that have
worked. A name with a drive (`"B:NAME.DAT"`) picks it for that file only. On CP/M 2.2, a drive
that isn't there stops the program with CP/M's own error.
