# 5.4 Memory options

*5 Options and compiler control*

**Option Memory** *kind* *start*, *size* [, *start*, *size*] ... - the memory map. One *kind* per
line, as many lines as you like, each a list of address/size pairs. It is the one directive for
saying what each stretch of memory is for:

| kind | meaning |
|---|---|
| `Reserved` | memory the program keeps out of (a screen, a buffer, a level loaded from disc); built round |
| `Paged` | the window where RAM pages / overlays swap in at run time |
| `Safe` | always-mapped RAM where the *safe classes* go (section [13](13.1-making-an-overlay-class.md)) |
| `Available` | usable RAM - the default, stated only to write a full map out |

<!-- nocheck -->
```basic
Option Memory Reserved &H8000, &H4000      ' #8000-#BFFF: the level loaded from disc
r = FileSystem.Load("LEVEL1.DAT", &H8000, &H4000)
```

The program is built round a `Reserved` or `Paged` range: it starts at the org and goes up, and
when the next part of it would reach into the range, that part and the rest go on after it.

**Option Deprecated** - older programs used separate directives for this: `Option Reserve`, the
`Option Page` *startbank* window form, `Option Safe Areas`, and `Option HighCode` / `Option Place`.
Those are deprecated - a program that uses one is refused unless it also has `Option Deprecated`,
which allows them all. Write new programs with `Option Memory`.

**Option Stack** *address* - the stack starts there and grows down. Without it the program
keeps the stack it was started with. On the `cpc` platform, moving the stack up frees
memory: everything from `#0040` to the stack is the program's.

**Option Memory Small** or **Option Memory CPCExpansion** [*maxpages*] - how the Memory class
(section [9](9.1-memory-summary.md)) and overlay classes reach RAM:

| | Small | CPCExpansion |
|---|---|---|
| What | one heap in main memory | 16K RAM pages through `#4000-#7FFF`, up to 4MB |
| Where | every platform; the default on cpm and test | the CPC platforms; their default |
| Code | about 900 bytes | about 2,100 bytes |
