# 5.4 Memory options

*5 Options and compiler control*

**Option Memory** *kind* *start*, *size* [, *start*, *size*] ... - the memory map. One *kind* per
line, as many lines as you like, each a list of address/size pairs. It is the one directive for
saying what each stretch of memory is for:

| kind | meaning |
|---|---|
| `Reserved [ZeroFill \| Skip]` | a gap the build goes round (a screen, a buffer, a level loaded from disc). `ZeroFill` (default): the gap is in the file, zeros. `Skip`: the file is packed, the start code moves the code above the gap up to its address |
| `Paged` *addr*, *size* [, *startbank*] | the window where RAM pages / overlays swap in. Code may sit under it (it is page 0, back when the page leaves); the data, the stubs, the library and any procedure a page calls never do. *startbank* (1) is the bank paging runs from; `0` makes the window itself a swap page, nothing under it |
| `Safe` | always-mapped RAM: the *safe classes'* procedures go there first, first fit over all the Safe ranges, and the fill goes on after them (section [13](13.1-making-an-overlay-class.md)) |
| `Available` | documentation - everything not Reserved is available. It also frees a platform's default Reserved range (the `cpc` / `cpcmin` screen at `#C000`, `cpcmin`'s firmware RAM `#A600-#BFFF`, `zxn`'s `#BA00` up) |

<!-- nocheck -->
```basic
Option Memory Reserved &H8000, &H4000      ' #8000-#BFFF: the level loaded from disc
r = FileSystem.Load("LEVEL1.DAT", &H8000, &H4000)
```

The program fills from the org upward and goes round `Reserved` only: when the next part of it
would reach into the range, that part and the rest go on after it. The assembler prints the map
it built (`NTC memory:` lines). The full rules, and a typical CPC map with double-buffered video
RAM in base block 1, are in `docs/memory-map.md`.

**Option Deprecated** - older programs used separate directives for this: `Option Reserve`, the
`Option Page` *startbank* window form, `Option Safe Areas`, and `Option HighCode` / `Option Place`.
Those are deprecated - a program that uses one is refused unless it also has `Option Deprecated`,
which allows them all. Write new programs with `Option Memory`.

**Option Stack** *address* - the stack starts there and grows down. Without it the program
keeps the stack it was started with. On the `cpc` platform, moving the stack up frees
memory: everything from `#0040` to the stack is the program's.

**Option Memory Small** or **Option Memory CPCExpansion** [*maxpages*] - how the Memory class
(section [9](9.1-memory-summary.md)) and overlay classes reach RAM:

| | Small | CPCExpansion |
|---|---|---|
| What | one heap in main memory | 16K RAM pages through `#4000-#7FFF`, up to 4MB |
| Where | every platform; the default on cpm and test | the CPC platforms; their default |
| Code | about 900 bytes | about 2,100 bytes |
