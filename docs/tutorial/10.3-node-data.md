# 10.3 A node's data

*10 The List library*

Each node has *size* bytes of data. Name the offsets with `Const`:

```basic
Const ID = 0, SCORE = 2, LEVEL = 4
Dim h As Long, n As Long, r As Integer
h = List.Create(5)
n = List.Append(h)
List.SetWord n, ID, 7
List.SetWord n, SCORE, 950
List.SetByte n, LEVEL, 3
Print List.GetWord(n, ID); " "; List.GetWord(n, SCORE); " "; List.GetByte(n, LEVEL)
Print Memory.ReadWord(List.Data(n) + SCORE)
r = List.Destroy(h)
```

```text
7 950 3
950
```

- `SetWord` / `GetWord`: a word (Integer) at an offset; `SetByte` / `GetByte`: a byte.
- `Data(node)` is a far pointer to the data: use it with `Memory.Copy`, `Memory.ReadWord` ...
  for text or bigger records.

Text and other bytes go in a node too: page [10.7](10.7-text-in-nodes.md).
