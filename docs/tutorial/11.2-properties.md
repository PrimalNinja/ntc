# 11.2 Properties

*11 Classes*

A property looks like a variable from outside, but runs code when it is read (`Get`) or
written (`Let`):

<!-- file: Bag.cls -->
**Bag.cls**

```basic
Private mItems(9) As Integer
Private mWrites As Integer

Public Property Get Item(ByVal i As Integer) As Integer
  Item = mItems(i)
End Property

Public Property Let Item(ByVal i As Integer, ByVal v As Integer)
  mItems(i) = v
  mWrites = mWrites + 1
End Property

Public Property Get Writes() As Integer
  Writes = mWrites
End Property
```

**Main.bas**

```basic
Bag.Item(3) = 42
Bag.Item(4) = Bag.Item(3) + 1
Print Bag.Item(4); " after "; Bag.Writes; " writes"
```

```text
43 after 2 writes
```

`Property Set` is the same as `Let`. A property can take arguments, like `Item(i)` here.
