# 4.8 Ending and checking

*4 Flow control*

- `End` (or `Stop`) ends the program. Falling off the end of the main program does too.
- `Error "text"` prints `Error: text` with the file and line, and stops.
- `Debug.Assert condition` stops with `Assert failed` when the condition is false.

```basic
Dim count As Integer
count = 3
Debug.Assert count >= 0
If count > 2 Then Print "done" : End
Print "not printed"
```

```text
done
```

NTC has no `On Error`. Routines that can fail give back a status - 0 or more is fine, below 0
is an error - and the program checks it:

<!-- nocheck -->
```basic
r = FileSystem.Save("HISCORE.DAT", VarPtr(hs), 20)
If r < 0 Then Print "Not saved: "; r
```

`Break name` puts a marker in the program that does nothing but can be stopped at in an
emulator's debugger.
