# 6.1 StdIO: the console

*6 The StdIO library*

`StdIO` is the console as a class. `Print`, `Input`, `Inkey`, `Cls` and `Locate` use it, so
the statements and the methods can be mixed.

| Member | Does |
|---|---|
| `PutStr s`, `PutChar c`, `PutInt n`, `NewLine`, `Tab col` | write ([6.2](6.2-writing.md)) |
| `GetLine s`, `GetChar()`, `GetKey()` | read ([6.3](6.3-reading.md)) |
| `Cls`, `Locate x, y`, `Mode m`, `Cols()`, `Column()`, `Row()` | the screen ([6.4](6.4-the-screen.md)) |
| `CanPosition`, `CanClear`, `CanInput`, `CanPoll`, `CanColour`, `Glyphs`, `Rows` | what this console can do |

What the console is on each platform:

| | cpc, cpcmin | cpcfw | cpm | test |
|---|---|---|---|---|
| Text drawn by | the program (CPC font) | the firmware | CP/M (BDOS) | ports |
| Size | 40 x 25 (mode 1) | 40 x 25 | a stream, or 80 x 24 with `Option Terminal` | 40 x 25 |
| `Locate`, `Cls` | yes | yes | only with `Option Terminal` | yes |
| `Mode` | yes | yes | no | yes |

The constants are fixed when compiling, so testing one costs nothing:

```basic
If StdIO.CanPosition Then
  Locate 1, StdIO.Rows : Print "bottom line";
Else
  Print "a stream: no bottom line"
End If
```
