# 6.2 Writing to the screen

*6 The StdIO library*

```basic
StdIO.PutStr "abc"
StdIO.PutChar 33
StdIO.NewLine
StdIO.PutInt 42
StdIO.Tab 6
StdIO.PutStr "col 6"
StdIO.NewLine
Print "Print mixes in"
```

```text
abc!
42   col 6
Print mixes in
```

| Method | Does |
|---|---|
| `PutStr s` | text, no new line |
| `PutChar c` | one character by its code (13 = new line) |
| `PutInt n` | an Integer |
| `NewLine` | a new line |
| `Tab col` | spaces up to that column |

`Print` does the same with less typing. The methods are there for your own console code and
for `StdIO` classes of your own ([6.5](6.5-your-own-stdio.md)).
