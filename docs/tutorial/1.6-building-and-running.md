# 1.6 Building and running

*1 The IDE and projects*

The IDE makes assembler. The assembler **sjasmplus** turns it into the program.

1. **Save .asm** downloads the project as `PROJECT.asm` (the project's name).
2. Assemble it:
   - CPC, with **AMSDOS .BIN** ticked: `sjasmplus PROJECT.asm` writes `PROJECT.BIN`.
   - CP/M: `sjasmplus --raw=PROJECT.COM PROJECT.asm`.
3. Run it:
   - CPC: put `PROJECT.BIN` on a disc image, M4 or SD card and type `RUN"PROJECT`.
   - CP/M: copy `PROJECT.COM` to the CP/M disc and type `PROJECT`.

A program with overlay classes also writes a page file for each page (`PROJECT.001` ...): put
them on the disc next to the program (section [13](13.2-building-the-files.md)).

Ready made builds: `src/build/` has every example as `.ASM` files for every platform, and
`build.bat` assembles them all (Windows). `src/build/dsk/` has disc images with the examples
already assembled - put one in WinAPE's drive A and `CAT`.

**Save .map** downloads a list of every label the compiler made, what it is, and the BASIC
name and line - handy in an emulator's debugger.

Without sjasmplus to hand, `src/test/ntcrun.py` runs a program on an emulated CPC or CP/M
(see `docs/NTC.md` section 6).
