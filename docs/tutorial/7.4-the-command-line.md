# 7.4 The command line

*7 The System library*

On CP/M, `A>WORDS HELLO THERE` starts `WORDS.COM` with the command line `HELLO THERE`.
`System.CommandLine` gives it (in capitals: CP/M makes it so). The CPC has no command line,
so ask instead:

<!-- run: cpm cmdline="hello there" -->
```basic
Dim cl As String
If System.HasCapability("COMMANDLINE") Then
  cl = System.CommandLine
Else
  Input "Command line"; cl
End If
Print "["; cl; "]"
```

```text
[HELLO THERE]
```

On the CPC the same program asks `Command line?` and takes what is typed. The full example,
which splits the line into words, is `bas/cmdline.bas`.

The program keeps a copy of the command line from the start, so it is still there after a
disc call or an `Input`.
