# 7.5 ROM commands

*7 The System library*

`System.Command(name)` runs a ROM's command - what CPC BASIC does with `|NAME` - with no
arguments. Only on `cpcfw` and `cpcmin`, where the firmware is there to find it.

<!-- platform: cpcfw -->
```basic
Option RomEnable All
Dim r As Integer
r = System.Command("DISC")
If r = -2 Then Print "No ROM has |DISC"
If r = -1 Then Print "No ROM commands on this platform"
```

| Result | Means |
|---|---|
| 0 | done |
| -2 | no ROM has that command |
| -1 | this platform can't (cpc, cpm, test) |

After `RUN"` the ROMs have been dropped: `Option RomEnable All` (or the ROM numbers) starts them
again so their commands are there ([5.5](5.5-platform-options.md)).
