# 13.3 Load, Unload and errors

*13 Class overlays*

The compiler gives every overlay class some members of its own:

| Member | Does |
|---|---|
| `Load()` | load it now (nothing if it is loaded): 0, a FileSystem status, -12 (no free page), -13 (see [13.5](13.5-one-overlay-area.md)) or -14 (the file is from another build) |
| `Unload()` | let it go; the next call loads it again |
| `Loaded()` | True when it is in memory |
| `Page()` | its RAM page (0 in one overlay area) |
| `LocalStart()`, `LocalSize()`, `LocalAlloc(size)`, `LocalFree(address)` | its local memory ([13.4](13.4-paged-variables-and-local-memory.md)) |

A call that has to load and can't stops the program:

```text
Overlay not loaded: GAME.001
The file didn't load
Press a key
```

To handle it yourself, `Load()` first and check:

<!-- nocheck -->
```basic
If Level1.Load() <> 0 Then
  Print "Put the game disc in" : End
End If
score = Level1.Play(score)
```
