# 13.1 Making an overlay class

*13 Class overlays*

Put `Option Class Overlay Name` at the top of a class. Its procedures are built into the page
Name, a file of its own; the rest of the program calls them as usual.

<!-- file: Level1.cls -->
**Level1.cls**

```basic
Option Class Overlay Level1
Public Function Play(ByVal score As Integer) As Integer
  Banner "Level 1"
  Play = score + 100
End Function
```

<!-- run: cpm -->
**Main.bas**

```basic
Option Reserve &H4000, &H4000
Dim score As Integer
score = Level1.Play(0)
Print "Score "; score; ", loaded "; Level1.Loaded()

Sub Banner(ByVal text As String)
  Print "== "; text; " =="
End Sub
```

```text
== Level 1 ==
Score 100, loaded -1
```

- The class's **code** goes in the file, built to run at `#4000`. Its **variables** stay in the
  program, so they keep their values whatever is loaded.
- An overlay can call the main program (`Banner` here), resident classes and other overlays.
- Without a name, the file is named after the class (up to 8 letters).
- Platforms: cpcmin, cpcfw and cpm (they can load files).
- The whole example, with two levels, is `bas/overlays/`.

Several classes in one page, or one class copied into several: [13.6](13.6-pages.md).
