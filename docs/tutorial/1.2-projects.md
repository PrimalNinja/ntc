# 1.2 Projects

*1 The IDE and projects*

A project is all the files that make one program. They are compiled together.

- **New project** starts again with one module, `Main.bas`.
- **Open...** adds files to the project: `.bas` and `.cls` files, a saved project (`.json`),
  or a VB5 / VB6 project (`.vbp`, picked together with its files - forms are left out).
  You can also drag files onto the file list.
- **Save project** downloads one `.json` file with every file in it, the platform and the
  start mode. Open it again later with **Open...**.
- **Example** replaces the project with one of the examples from `src/bas/`.

The browser also keeps the project between visits, so closing the page loses nothing. That
copy lives in this browser only: use **Save project** to keep a project safe or move it.

Under the file list: **+ Module** and **+ Class** make a new file, **Rename** renames the
selected file, **Remove** takes it out of the project. Renaming a file to end in `.cls` makes
it a class, `.bas` a module.
