# 10.2 Making and walking a list

*10 The List library*

```basic
Dim h As Long, n As Long, i As Integer, r As Integer
h = List.Create(2)                 ' 2 data bytes a node: one word
For i = 1 To 5
  n = List.Append(h)
  List.SetWord n, 0, i * i
Next
Print "count "; List.Count(h)
n = List.First(h)
Do While n <> 0
  Print List.GetWord(n, 0); " ";
  n = List.NextOf(n)
Loop
Print
n = List.Last(h)
Print "last "; List.GetWord(n, 0); ", before it "; List.GetWord(List.PrevOf(n), 0)
r = List.Destroy(h)
```

```text
count 5
1 4 9 16 25
last 25, before it 16
```

- A list is a handle (a Long). Keep as many as you like.
- A node is a far pointer (a Long). `Append` and `Prepend` give a new node, cleared to 0, at
  the end / the start; 0 = no room.
- `First`, `Last`, `NextOf`, `PrevOf` give a node, or 0 past the end.
- `Destroy` gives all the list's memory back.
