# 6.4 The screen

*6 The StdIO library*

```basic
Cls
Locate 10, 3
Print "here"
Print "columns "; StdIO.Cols(); ", cursor at "; StdIO.Column(); ","; StdIO.Row()
```

- `Cls` clears and puts the cursor top left.
- `Locate column, row` moves it; 1, 1 is the top left (column first, as CPC BASIC).
- `Mode 0 / 1 / 2` sets the CPC screen mode: 20, 40 or 80 columns.
- `StdIO.Cols()` is the width now; `Column()` and `Row()` the cursor.
- `Frame` waits for the next frame flyback (50 a second on a CPC): put it in an animation
  loop to stop flicker.

On CP/M without `Option Terminal`, `Cls` starts a new line and `Locate` does nothing: check
`StdIO.CanPosition` before drawing a screen layout ([6.1](6.1-stdio-summary.md)).
