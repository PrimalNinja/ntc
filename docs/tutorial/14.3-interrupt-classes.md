# 14.3 Interrupt classes

*14 Interrupt handlers*

`Option Class Interrupt rate` at the top of a class runs its `Sub Tick()` *rate* times a second
(1-300). `Option Class Interrupt Frame` runs it once a frame, just after the vertical sync.

<!-- file: Clock.cls -->
**Clock.cls**

```basic
Option Class Interrupt 1
Public Seconds As Integer
Public Sub Tick()
  Seconds = Seconds + 1
End Sub
```

<!-- platform: cpc -->
**Main.bas**

```basic
Option Turbo Off
Do
  Locate 1, 1 : Print "Seconds: "; Clock.Seconds
  Frame
Loop Until Inkey <> 0
```

- The class must have a `Public Sub Tick()` with no parameters.
- Up to 4 interrupt classes. Classes with the same rate take turns, so they don't all run on
  the same interrupt.
- `Tick` is ordinary BASIC, run at the next safe point: keep it short.
- Normal mode only; in turbo mode `Tick` waits.
- cpc and cpcmin (NTC's own interrupt handler at `#38`) and cpcfw (a firmware fast ticker
  event, 300 a second; the free RAM then ends at `#A5F0`, where the event's block sits).

The example `bas/interrupts/` has a clock and a moving star, each its own class.
