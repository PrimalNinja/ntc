# 4.2 If

*4 Flow control*

```basic
Dim x As Integer
x = 7
If x > 5 Then Print "big" Else Print "small"
If x Mod 2 = 0 Then
  Print "even"
ElseIf x = 7 Then
  Print "seven"
Else
  Print "odd"
End If
Print IIf(x > 5, "yes", "no"); " "; Choose(2, "a", "b", "c")
```

```text
big
seven
yes b
```

- The one line form can hold several statements: `If x > 5 Then a = 1 : b = 2`.
- Compares: `=` `<>` `<` `<=` `>` `>=`. Join them with `And`, `Or`, `Not`.
- Text compares letter by letter; `Option Compare Text` ignores case.
- `IIf(c, a, b)` gives a or b. `Choose(n, a, b, ...)` gives the nth value.
- Both sides of `And` / `Or`, and both values of `IIf`, are always worked out.
