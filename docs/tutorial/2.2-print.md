# 2.2 Print

*2 Hello World*

`Print` shows numbers and text.

```basic
Print "a"; 1; "b", 2
Print "no new line";
Print "!"
Print
Print "x"; Tab(5); "y"; Spc(3); "z"
```

```text
a1b 2
no new line!

x   y   z
```

- `;` between items: nothing between them.
- `,` between items: one space.
- `;` or `,` at the end: the next `Print` carries on on the same line.
- `Print` on its own: an empty line.
- `Tab(n)` moves to column n; `Spc(n)` prints n spaces.
- `?` is short for `Print`.

Numbers print without spaces around them. VB puts a space before a positive number and one
after every number: `Option VBPrint` makes NTC do the same.

Long text carries on at the start of the next line. The CPC screen is 40 columns in mode 1.
