# 3.4 Maths functions

*3 Calculations and maths*

```basic
Print Abs(-37); ","; Sgn(-9); Sgn(0); Sgn(5); ","; Sqr(17)
Randomize 7
Print Rnd(6) + 1
```

| Function | Gives |
|---|---|
| `Abs(n)` | n without its sign |
| `Sgn(n)` | 1, 0 or -1 |
| `Sqr(n)` | the whole number square root, rounded down |
| `Rnd(n)` | a random number from 0 to n-1 |
| `Randomize [seed]` | starts the random numbers again: from *seed*, or from the tick count |
| `Int(n)`, `Fix(n)` | n (numbers are whole already) |

`Rnd(6) + 1` is a dice throw. With the same seed, `Randomize 7` gives the same numbers
every run - good for testing.
