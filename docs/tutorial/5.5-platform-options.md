# 5.5 Platform options

*5 Options and compiler control*

**Option RomEnable 7** (or `All`) - CPC firmware platforms (`cpcfw`, `cpcmin`). `RUN"NAME` of
a binary resets the firmware and drops AMSDOS, so files would go to tape. With this option the
program starts AMSDOS (ROM 7) again first thing - or every background ROM with `All`.

<!-- platform: cpcfw -->
```basic
Option RomEnable 7
Dim hs(9) As Integer, r As Integer
r = FileSystem.Save("HISCORE.DAT", VarPtr(hs), 20)
Print "saved: "; r
```

**Option Terminal VT52 / ANSI / None** - CP/M only. Says which codes the terminal knows, so
`Cls` clears the screen and `Locate` moves the cursor. `VT52` suits Amstrad CP/M (CPC and
PCW); `ANSI` most emulators. Without it the console is a stream: `Cls` starts a new line and
`Locate` does nothing.

<!-- platform: cpm -->
```basic
Option Terminal VT52
Cls
Locate 10, 3
Print "here"
```

Both give a warning and do nothing on the platforms they aren't for, so one source builds
everywhere.
