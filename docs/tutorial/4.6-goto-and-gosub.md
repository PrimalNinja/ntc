# 4.6 GoTo and GoSub

*4 Flow control*

`GoTo` jumps to a label. `GoSub` jumps and comes back at `Return`.

```basic
Dim x As Integer
GoSub hello
GoSub hello
x = 2
On x GoTo one, two
Print "none"
one: Print "one"
End
two: Print "two"
End
hello:
  Print "hi"
  Return
```

```text
hi
hi
two
```

- A label is a name followed by `:`, or a line number.
- Labels belong to their procedure: a `GoTo` can't jump into or out of a Sub.
- `On n GoTo a, b, c` goes to the nth label; any other n carries on.

Loops and Subs are easier to read; `GoTo` and `GoSub` are here for old programs and for
the odd fast jump.
