# 9.2 Where things are

*9 The Memory library*

Main memory from the program up to the top of free RAM:

```basic
Print "program  &"; Hex$(Memory.ProgramStart()); "-&"; Hex$(Memory.ProgramEnd() - 1)
Print "heap     &"; Hex$(Memory.HeapStart()); "-&"; Hex$(Memory.HeapEnd() - 1)
Print "top      &"; Hex$(Memory.Top())
Print "stack at &"; Hex$(Memory.StackTop())
```

| Method | Gives |
|---|---|
| `ProgramStart()` | where the program starts (CPC `#0040`, CP/M `#0100`) |
| `ProgramEnd()` | the first byte after the program and its arrays |
| `Top()` | the top of free RAM: CPC `#A600` (the firmware above), CP/M the end of the TPA (the BDOS starts there), test `#C000` |
| `StackTop()` | where the stack starts (it grows down) |
| `HeapStart()`, `HeapEnd()` | `Small`: the heap (`HeapEnd` is the first byte past it) |
| `TableEnd()` | `CPCExpansion`: the end of the class's page tables (just after the program) |

Addresses above `&7FFF` are negative as Integers (`&A600` is -23040). `Hex$` shows them right;
for sizes, work in Longs: `CLng(a) + 65536` when `a` is below 0. `bas/memmap.bas` draws the
whole map, with how much RAM is free - on CP/M, how much of the TPA.
