# 7.3 Capabilities

*7 The System library*

`System.HasCapability(name)` is True when this platform can do something. Case doesn't
matter, and a name it doesn't know is False - so a program can ask about anything.

```basic
Print System.HasCapability("clock"); System.HasCapability("FILES"); System.HasCapability("flying")
```

```text
-100
```

| Name | Means | cpc | cpcmin | cpcfw | cpm | test |
|---|---|---|---|---|---|---|
| `COMMANDLINE` | `System.CommandLine` has the command tail | - | - | - | yes | - |
| `SCREEN` | rows and columns, not a stream | yes | yes | yes | with `Option Terminal` | yes |
| `KEYBOARD` | keys | yes | yes | yes | yes | yes |
| `CLOCK` | `Ticks` counts | yes | yes | yes | - | yes |
| `HOOK` | the `Interrupt` statement | yes | yes | - | - | - |
| `INTERRUPTCLASSES` | `Option Class Interrupt` | yes | yes | - | - | - |
| `PAGES` | RAM pages (`Option Memory CPCExpansion`) | yes | yes | yes | - | - |
| `FILES` | `FileSystem` | - | yes | yes | yes | - |
| `ROMCOMMANDS` | `System.Command` | - | yes | yes | - | - |
| `OVERLAYS` | `Option Class Overlay` | - | yes | yes | yes | - |

`FileSystem.Capability(name)` goes into more detail about files ([8.1](8.1-filesystem-summary.md)).
