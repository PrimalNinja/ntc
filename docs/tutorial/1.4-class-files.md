# 1.4 Class files

*1 The IDE and projects*

A class is a `.cls` file. Its variables and procedures are its members. Make one with
**+ Class**, or rename a file to end in `.cls`.

<!-- file: Counter.cls -->
**Counter.cls**

```basic
Private mTotal As Integer

Public Sub Add(ByVal v As Integer)
  mTotal = mTotal + v
End Sub

Public Property Get Total() As Integer
  Total = mTotal
End Property
```

**Main.bas**

```basic
Dim c As New Counter
c.Add 5
c.Add 7
Print c.Total
```

```text
12
```

NTC classes have one set of members each: there are no objects made while the program runs.
Section [11](11.1-a-first-class.md) goes through classes properly.

Some classes come with the platform and join the project by themselves when you use them:
`StdIO`, `System`, `FileSystem`, `Memory` and `List` (sections 6 to 10).
