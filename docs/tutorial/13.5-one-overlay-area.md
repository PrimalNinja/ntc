# 13.5 One overlay area

*13 Class overlays*

On CP/M, and on cpcmin / cpcfw with `Option Memory Small` (a 64K CPC), there are no RAM
pages: `#4000-#7FFF` is **one overlay area**, holding one overlay class at a time.

<!-- file: A.cls -->
**A.cls**

```basic
Option Class Overlay "OVA"
Public Function Deep(ByVal x As Integer) As Integer
  Print "A";
  Deep = B.Mid(x) + 1
  Print " back in A"
End Function
Public Function Twice(ByVal x As Integer) As Integer
  Twice = x * 2
End Function
```

<!-- file: B.cls -->
**B.cls**

```basic
Option Class Overlay "OVB"
Public Function Mid(ByVal x As Integer) As Integer
  Print " B";
  Mid = A.Twice(x) + 10
  Print " back in B";
End Function
```

<!-- run: cpm -->
**Main.bas**

```basic
Option Reserve &H4000, &H4000
Print A.Deep(3)
Print "B in the area: "; B.Loaded(); ", A: "; A.Loaded()
```

```text
A B back in B back in A
17
B in the area: 0, A: -1
```

What happened: `A.Deep` loaded A; A called B, which loaded B over A; B called `A.Twice`, which
loaded A over B; the return into B loaded B again, and the return into A loaded A again. It
works, but each of those is a disc load. Keep code that calls itself a lot in one class.

- `Load()` / `Unload()` called from code in the area give -13: loading would overwrite the code
  that is running.
- The heap (`Memory`, `List`) gets the RAM between the program's end and `#4000`.
