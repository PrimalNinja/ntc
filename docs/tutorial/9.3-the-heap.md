# 9.3 The heap

*9 The Memory library*

`Alloc(size)` gives a **far pointer**: a Long, the address in the low word and the RAM page in
the high word (0 = plain main memory). Read and write through it with the class's methods:

```basic
Dim p As Long, q As Long, r As Integer, i As Integer, s As Integer
p = Memory.Alloc(100)
If p = 0 Then Print "no room" : End
For i = 0 To 99 : Memory.WriteByte p + i, i : Next
q = Memory.Alloc(100)
r = Memory.Copy(p, q, 100)
For i = 0 To 99 : s = s + Memory.ReadByte(q + i) : Next
Memory.WriteWord q, 1234
Print "sum "; s; ", word "; Memory.ReadWord(q)
r = Memory.Free(q)
r = Memory.Free(p)
Print "freed "; r
```

```text
sum 4950, word 1234
freed 0
```

| Method | Does |
|---|---|
| `Alloc(size)` | a block of up to 16382 bytes; 0 = no room |
| `Free(ptr)` | the block back (`BadPage` if it isn't one) |
| `Largest()` | the biggest block `Alloc` could give now |
| `ReadByte(ptr)`, `ReadWord(ptr)`, `WriteByte ptr, v`, `WriteWord ptr, v` | one byte / word |
| `Copy(src, dst, length)` | far pointer to far pointer; main memory is page 0 |
| `PageOf(ptr)` | its page |
| `Address(ptr)` | switches its page in and gives the plain address (then `Peek` / `Poke` work) |

The methods switch the block's page in and put the window back afterwards, so a far pointer
works wherever the block is. With `Small` everything is page 0 and nothing is switched.
