# 8.3 Reading files

*8 The FileSystem library*

Reading a file in order (CP/M): `Open` it `ForRead`, read until `Eof`, `Close` it.

<!-- run: cpm files="NOTES.TXT=first line\nsecond line\n" -->
```basic
Dim h As Integer, r As Integer, n As Integer
h = FileSystem.Open("NOTES.TXT", FileSystem.ForRead)
If h < 0 Then Print "Can't open: "; h : End
Do While Not FileSystem.Eof(h)
  n = n + 1
  Print n; ": "; FileSystem.ReadLine(h)
Loop
r = FileSystem.Close(h)
```

```text
1: first line
2: second line
```

| Method | Does |
|---|---|
| `Open(name, FileSystem.ForRead)` | a handle (0 or more), or a status; the file must be there |
| `ReadLine(h)` | the next line (CR LF or LF ends it) |
| `ReadByte(h)` | the next byte, 0-255, or `EndOfFile` |
| `Read(h, address, count)` | bytes into memory; gives how many it got |
| `Eof(h)` | True when nothing is left |
| `Close(h)` | done with it |

Text ends at the first ^Z (CP/M's end of text mark). Two files can be open at once.
