# 11.1 A first class

*11 Classes*

A class keeps some data and the procedures that work on it together. It is a `.cls` file:

<!-- file: Counter.cls -->
**Counter.cls**

```basic
Private mTotal As Integer

Public Sub Add(ByVal v As Integer)
  mTotal = mTotal + v
End Sub

Public Sub Reset()
  mTotal = 0
End Sub

Public Function Total() As Integer
  Total = mTotal
End Function
```

**Main.bas**

```basic
Counter.Add 5
Counter.Add 7
Print Counter.Total()
Counter.Reset
Print Counter.Total()
```

```text
12
0
```

- The file's name is the class's name.
- `Public` members are seen outside; `Private` ones only inside the class.
- Call a member as `Class.Member`.
