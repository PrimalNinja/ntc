# 4.3 Select Case

*4 Flow control*

```basic
Dim n As Integer
For n = 1 To 8 Step 3
  Select Case n
    Case 1, 2: Print n; " low"
    Case 3 To 6: Print n; " mid"
    Case Is > 6: Print n; " high"
    Case Else: Print n; " other"
  End Select
Next
```

```text
1 low
4 mid
7 high
```

- The first `Case` that matches runs; the others are skipped.
- A case can be a list (`1, 2`), a range (`3 To 6`) or a compare (`Is > 6`).
- It works on text too: `Case "Y", "y"`.
