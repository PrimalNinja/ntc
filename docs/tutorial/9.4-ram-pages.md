# 9.4 RAM pages

*9 The Memory library*

With `Option Memory CPCExpansion`, the CPC's extra RAM comes in 16K **pages**, switched into
`#4000-#7FFF` (the **window**). Page 1 is main RAM's own `#4000`; a 6128 has pages 1-5.

<!-- run: cpc ram=128 -->
```basic
Option Reserve &H4000, &H4000
Dim pg As Integer, a As Integer
Print Memory.RamSize(); "K, pages "; Memory.Pages(); ", free "; Memory.FreePages()
pg = Memory.AllocPage(Memory.TypeUser)
a = Memory.SelectPage(pg)
Poke a, 77
a = Memory.SelectPage(1)
Print "page "; pg; " is "; Chr$(Memory.PageType(pg)); ", map "; Memory.Map(1, 5)
a = Memory.SelectPage(pg)
Print "byte "; Peek(a)
a = Memory.FreePage(pg)
```

```text
128K, pages 5, free 5
page 1 is U, map U----
byte 77
```

| Method | Does |
|---|---|
| `Pages()`, `FreePages()`, `RamSize()` | how many, how many free, K of RAM |
| `AllocPage(kind)` | a free page for `TypeCode`, `TypeData`, `TypeIrq` or `TypeUser`; 0 = none |
| `FreePage(page)` | back to free |
| `SelectPage(page)` | into the window; gives `Memory.WindowStart` (`&H4000`) |
| `CurrentPage()` | the page in the window |
| `PageType(page)` | its letter: `C` code, `D` heap data, `I` interrupt, `U` user, `-` free |
| `Map(first, count)` | one letter per page, as text |

The program and its stack must stay out of the window (`Option Reserve &H4000, &H4000` checks
it when assembling). `TypeUser` pages are yours: music, a level, a screen. `TypeData` pages
hold the heap; `TypeCode` pages, overlay classes (section 13).
