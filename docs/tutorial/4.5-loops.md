# 4.5 Do, While and Exit

*4 Flow control*

```basic
Dim n As Integer
n = 0
Do
  n = n + 3
Loop Until n > 10
Print n
n = 1
Do While n < 100
  n = n * 2
Loop
Print n
While n > 3
  n = n \ 3
Wend
Print n
```

```text
12
128
1
```

- `Do While c` / `Do Until c` test at the top; `Loop While c` / `Loop Until c` at the bottom
  (the loop runs at least once).
- A plain `Do ... Loop` repeats until `Exit Do`.
- `Exit For`, `Exit Do`, `Exit While` leave the loop now; `Exit Sub` / `Exit Function` leave
  the procedure.

```basic
Dim i As Integer
For i = 1 To 100
  If i * i > 50 Then Exit For
Next
Print i
```

```text
8
```
