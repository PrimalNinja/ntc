# 12.2 Paging from BASIC

*12 Paging and overlays*

The Memory class does the switching (section [9.4](9.4-ram-pages.md)): ask for a page, select it,
use `#4000-#7FFF`, select another.

<!-- run: cpc ram=576 -->
```basic
Option Reserve &H4000, &H4000
Dim a As Integer, b As Integer, w As Integer
a = Memory.AllocPage(Memory.TypeUser)
b = Memory.AllocPage(Memory.TypeUser)
w = Memory.SelectPage(a) : Poke w, 1
w = Memory.SelectPage(b) : Poke w, 2
w = Memory.SelectPage(a)
Print "page "; a; ": "; Peek(w);
w = Memory.SelectPage(b)
Print ", page "; b; ": "; Peek(w)
Print Memory.Pages(); " pages on this machine"
```

```text
page 1: 1, page 2: 2
33 pages on this machine
```

The same address, `#4000`, holds different bytes depending on the page in the window. That is
all paging is. What goes in a page:

- data the program loads and switches to: music, levels, graphics (`TypeUser`);
- the heap - `Alloc` and lists use pages by themselves (`TypeData`);
- code: overlay classes (`TypeCode`, section 13).
