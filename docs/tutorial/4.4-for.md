# 4.4 For and For Each

*4 Flow control*

```basic
Dim i As Integer
For i = 1 To 5
  Print i;
Next
Print
For i = 10 To 1 Step -3
  Print i; " ";
Next
Print
```

```text
12345
10 7 4 1
```

- The end and the step are worked out once, at the start.
- If the start is already past the end, the loop doesn't run.
- `Next i, j` closes two loops.
- An Integer loop to 32767 ends there - use a Long to count further.

`For Each` takes each element of an array:

```basic
Dim a(2) As Integer, v As Integer
a(0) = 4 : a(1) = 5 : a(2) = 6
For Each v In a
  Print v;
Next
Print
```

```text
456
```
