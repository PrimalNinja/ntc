# 8.6 Delete, rename, exists, size

*8 The FileSystem library*

<!-- run: cpm -->
```basic
Dim r As Integer, b(63) As Integer
r = FileSystem.Save("OLD.DAT", VarPtr(b), 128)
Print "exists "; FileSystem.Exists("OLD.DAT"); ", size "; FileSystem.Size("OLD.DAT")
r = FileSystem.Rename("OLD.DAT", "NEW.DAT")
Print "renamed "; r; ", old there "; FileSystem.Exists("OLD.DAT")
r = FileSystem.Delete("NEW.DAT")
Print "deleted "; r; ", there "; FileSystem.Exists("NEW.DAT")
```

```text
exists -1, size 128
renamed 0, old there 0
deleted 0, there 0
```

| Method | Gives |
|---|---|
| `Exists(name)` | True / False |
| `Size(name)` | bytes, a Long (CP/M: whole 128 byte records) |
| `Rename(old, new)` | 0, or `NotFound`, `AlreadyExists` |
| `Delete(name)` | 0, or `NotFound` |

CP/M only. Names are 8.3 (`NAME.EXT`), with an optional drive: `B:NAME.EXT`. No `*` or `?`.
