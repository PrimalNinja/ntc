# 1.1 The IDE

*1 The IDE and projects*

The IDE is one web page: `src/ntc.html`. Open it in a browser. Nothing gets installed and it
works offline. It compiles your BASIC into Z80 assembler while you type.

The screen has three panes:

| Pane | What is in it |
|---|---|
| Left, top | the files in your project: modules (`.bas`) and classes (`.cls`) |
| Left, bottom | the procedures in the selected file. Click one to jump to it. A `-` after its kind means nothing calls it |
| Middle | the BASIC of the selected file - this is where you type |
| Right | the compiled program: NTC assembler for the whole project, with its size |

Along the top: **New project**, **Open...**, **Save project**, and **Example**, which loads
one of the example programs. Along the bottom: the settings (see [1.5](1.5-settings.md)) and
**Copy**, **Save .asm** and **Save .map**.

Errors appear under the panes with their file and line. Click one to go to the line.

Try it: pick **Example** -> *Hello* (or any example), and watch the right pane fill. Change a
line in the middle pane: the right pane follows a moment later.
