# 10.4 Insert, delete and search

*10 The List library*

```basic
Dim h As Long, n As Long, m As Long, i As Integer, r As Integer
h = List.Create(2)
For i = 1 To 5 : n = List.Append(h) : List.SetWord n, 0, i * 10 : Next
m = List.Search(h, 0, 30)              ' the node holding 30
n = List.InsertAfter(h, m) : List.SetWord n, 0, 35
r = List.Delete(h, List.First(h))
n = List.Prepend(h) : List.SetWord n, 0, 5
n = List.First(h)
Do While n <> 0
  Print List.GetWord(n, 0); " ";
  n = List.NextOf(n)
Loop
Print
Print "not there: "; List.Search(h, 0, 99)
r = List.Destroy(h)
```

```text
5 20 30 35 40 50
not there: 0
```

- `InsertAfter(h, node)` puts a new node after that one (node 0: at the start).
- `Delete(h, node)` takes it out; its memory goes back to the list for the next new node.
- `Search(h, offset, value)` finds the first node with that word at that offset, or 0.

Adding and deleting is quick at any place in the list - no moving of the rest, as an array
would need.
