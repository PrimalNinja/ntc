# 11.4 Me, With and kinds of class

*11 Classes*

`Me.member` inside a class means its own member. `With` saves typing the name:

<!-- file: Point.cls -->
**Point.cls**

```basic
Public X As Integer, Y As Integer
Public Sub MoveBy(ByVal dx As Integer, ByVal dy As Integer)
  Me.X = Me.X + dx
  Y = Y + dy
End Sub
```

**Main.bas**

```basic
With Point
  .X = 3
  .Y = 4
  .MoveBy 1, 1
  Print .X; ","; .Y
End With
```

```text
4,5
```

`Option Class` at the top of a `.cls` says what kind of class it is:

| | Means | Section |
|---|---|---|
| `Option Class Resident` (or nothing) | part of the program, as above | |
| `Option Class Overlay "FILE"` | its code goes in its own file, loaded at `#4000` when called | [13](13.1-making-an-overlay-class.md) |
| `Option Class Interrupt rate` | its `Tick` runs *rate* times a second | [14](14.3-interrupt-classes.md) |
