# 5.1 Options and directives

*5 Options and compiler control*

Options change how the compiler builds the program. They can go anywhere, but the top of
the main module is the usual place. Directives (`#...`) pick which lines get compiled.

| Keyword | Does | Page |
|---|---|---|
| `Option Explicit` | every variable must be declared | [5.2](5.2-language-options.md) |
| `Option Base 0 / 1` | the default low bound of arrays | [5.2](5.2-language-options.md) |
| `Option Compare Text` | text compares ignore case | [5.2](5.2-language-options.md) |
| `Option VBPrint` | `Print` spaces numbers as VB does | [5.2](5.2-language-options.md) |
| `Option Turbo`, `Option Turbo Off` | start in turbo / normal mode | [5.3](5.3-turbo-and-normal.md) |
| `Option NoTurbo` | normal mode only (smaller) | [5.3](5.3-turbo-and-normal.md) |
| `Turbo On`, `Turbo Off`, `DoEvents` | switch mode while running; a safe point | [5.3](5.3-turbo-and-normal.md) |
| `Option Reserve start, size` | memory the program must stay out of | [5.4](5.4-memory-options.md) |
| `Option Stack address` | where the stack goes | [5.4](5.4-memory-options.md) |
| `Option Memory Small / CPCExpansion` | how the Memory class reaches RAM | [5.4](5.4-memory-options.md) |
| `Option RomEnable 7 / All` | CPC: start AMSDOS (and other ROMs) again after `RUN"` | [5.5](5.5-platform-options.md) |
| `Option Terminal VT52 / ANSI` | CP/M: the terminal's codes, for `Cls` and `Locate` | [5.5](5.5-platform-options.md) |
| `Option Class ...` | what kind of class a `.cls` is | [13.1](13.1-making-an-overlay-class.md), [14.3](14.3-interrupt-classes.md) |
| `#Const`, `#If ... #ElseIf ... #Else ... #End If` | compile one part, skip others | [5.6](5.6-conditional-compiling.md) |
| `#asm ... #endasm`, `Break` | Z80 code in the program; a debugger marker | [5.7](5.7-inline-assembly.md) |
