# 7.2 Ticks and timing

*7 The System library*

`Ticks` (or `System.Ticks()`, or `Timer`) counts up `System.TicksPerSecond` times a second.

```basic
Dim t As Integer, i As Integer, s As Long
t = Ticks
For i = 1 To 2000 : s = s + i : Next
Print "took "; Ticks - t; " ticks of "; System.TicksPerSecond; " a second"
```

| Platform | Ticks |
|---|---|
| cpc, cpcmin | interrupts, 300 a second - normal mode only (turbo has no interrupts) |
| cpcfw | the firmware's clock, 300 a second, both modes |
| cpm | always 0: there is no clock |
| test | 300 a second of emulated time |

To time turbo code on the CPC, use a stopwatch - or time it in normal mode. Seconds and
hundredths from ticks:

<!-- nocheck -->
```basic
Print t \ System.TicksPerSecond; "."; (t Mod System.TicksPerSecond) * 100 \ System.TicksPerSecond
```

`Frame` waits for the next screen frame (50 a second on a CPC) - the way to pace a game.
