# 6.3 Reading the keyboard

*6 The StdIO library*

<!-- run: test keys="hello\nk" -->
```basic
Dim s As String, k As Integer
StdIO.PutStr "Type: "
StdIO.GetLine s
Print "got "; s
k = StdIO.GetChar()
Print "key "; k; " "; Chr$(k)
Print "now: "; StdIO.GetKey()
```

```text
Type: hello
got hello
key 107 k
now: 0
```

| Method | Statement | Does |
|---|---|---|
| `GetLine s` | `Input s` | waits for a line ended with Enter |
| `GetChar()` | - | waits for a key, gives its code |
| `GetKey()` | `Inkey` | the key pressed, 0 if none - doesn't wait |

`Inkey$` gives the key as text ("" if none). A loop that waits for any key:

<!-- nocheck -->
```basic
Do While Inkey <> 0 : Loop          ' let go of any key held down
Do : Frame : Loop Until Inkey <> 0  ' then wait for a new one
```
