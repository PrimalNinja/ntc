# 3.5 Bits, hex and conversions

*3 Calculations and maths*

`And`, `Or`, `Xor` and `Not` work on every bit. True is -1 (all bits set), so they also join
compares.

```basic
Print 5 And 3; ","; 5 Or 3; ","; 5 Xor 3; ","; Not 0
Print Hex$(255); ","; Hex$(-1); ","; &HFF; ","; &X101
Print CByte(300); ","; CInt(70000&); ","; CBool(5)
```

```text
1,7,6,-1
FF,FFFF,255,5
44,4464,-1
```

| Written | Means |
|---|---|
| `&HFF`, `&FF`, `#FF` | hexadecimal |
| `&X101` | binary |
| `&O17` | octal |
| `Hex$(n)`, `Oct$(n)` | n as hex / octal text |
| `CInt`, `CLng` | to Integer (low 16 bits) / Long |
| `CByte` | low 8 bits |
| `CBool` | True for anything but 0 |

Testing a bit: `If flags And 4 Then ...`. Setting one: `flags = flags Or 4`. Clearing one:
`flags = flags And Not 4`.
