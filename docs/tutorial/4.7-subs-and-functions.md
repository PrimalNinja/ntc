# 4.7 Subs and Functions

*4 Flow control*

A `Sub` does something. A `Function` gives a value back: assign it to the function's name.

```basic
Greet "Ann"
Call Greet("Bob")
Print Twice(21)
Dim x As Integer
x = 5
Bump x
Bump x, 10
Print x

Sub Greet(ByVal who As String)
  Print "Hello "; who
End Sub

Function Twice(ByVal n As Integer) As Integer
  Twice = n * 2
End Function

Sub Bump(n As Integer, Optional ByVal by As Integer = 1)
  n = n + by
End Sub
```

```text
Hello Ann
Hello Bob
42
16
```

- `ByVal` gives the Sub a copy; `ByRef` (the default) changes the caller's variable when the
  Sub ends.
- `Optional` parameters can be left out; they get their default.
- Locals (`Dim` inside) start at 0 / "" every call; `Static` ones keep their value.
- A Sub can't call itself (no recursion): each has one set of locals.
- A Function called as a statement gives a warning: its result - often a status - is lost.
