# 5.7 Z80 code in the program

*5 Options and compiler control*

`#asm ... #endasm` puts Z80 code straight into the program. `{name}` is replaced by the label
of a variable, constant or BASIC label:

```basic
Dim n As Integer
n = 20
#asm
            ld hl, ({n})
            inc hl
            ld ({n}), hl
#endasm
Print n
```

```text
21
```

The rules (NTC's stack pointer walks the program):

- no `call` or `push` unless you switch to the real stack first;
- no register keeps its value from one block to the next;
- interrupts are off inside the block.

A Sub or Function whose whole body is one `#asm` block becomes a keyword of its own: each
argument arrives as an address on the stack, a Function's result address last. See the user
guide, section 14.

`Break name` puts a do-nothing marker `bp_name` in the program, to stop at in an emulator's
debugger. **Save .map** lists every label with its BASIC line.
