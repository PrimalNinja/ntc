# 5.2 Language options

*5 Options and compiler control*

```basic
Option Explicit
Option Compare Text
Dim a As String
a = "Hello"
Print a = "HELLO"; " "; "abc" Like "A*"
```

```text
-1 -1
```

- **Option Explicit**: a variable used without `Dim` is an error. Without it, a new name is
  made up as it goes: `a$` a String, `n` an Integer. Keep it on - a typo then fails to
  compile instead of making a new variable.
- **Option Base 1**: `Dim a(5)` runs 1 to 5 instead of 0 to 5 (this module only).
  `Dim a(1 To 5)` says it either way.
- **Option Compare Text**: `=`, `<`, `Like`, `InStr`, `Select Case` ... on text ignore case
  (this module only).
- **Option VBPrint**: `Print 5` shows `" 5 "` as VB does, and `,` moves to the next 14
  column zone.
