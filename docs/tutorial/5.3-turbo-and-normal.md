# 5.3 Turbo and normal mode

*5 Options and compiler control*

Every NTC program runs in one of two modes:

| | Turbo | Normal |
|---|---|---|
| Interrupts | off the whole time | let in at safe points (jumps, loops, calls) |
| Speed | full | loops and calls a little slower |
| `Ticks`, `Interrupt`, interrupt classes | stand still | work |

A program starts in normal mode, unless `Option Turbo` (or the IDE's **Start mode**) says
turbo. `Option Turbo Off` makes it start in normal mode whatever the IDE says.

`Turbo On` / `Turbo Off` switch while running. An `If`, a loop or a Sub must end in the mode it
started in, so the compiler always knows the mode. If a part of an `If` or a loop doesn't, the
compiler switches back at its end and warns you (it happens when this example is built with
the start mode set to turbo and without `Option Turbo Off`):

```basic
Option Turbo Off
Dim fast As Integer
fast = -1
If fast Then
  Turbo On
  Work
  Turbo Off
Else
  Work
End If
Print "done"

Sub Work()
  Dim i As Integer, s As Long
  For i = 1 To 1000 : s = s + i : Next
End Sub
```

```text
done
```

`Work` is called in both modes, so it is built twice. **Option NoTurbo** builds normal mode
only: smaller, and `Turbo On` / `Off` do nothing.

`DoEvents` is a safe point by itself: put one in a long run of straight code that needs
interrupts to keep up.

How much faster is turbo? From 2% to 55%, depending on the code - try `bas/shellsort.bas`
and `bas/sorttime.bas`.
