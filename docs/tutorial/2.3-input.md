# 2.3 Asking questions

*2 Hello World*

`Input` waits for a line typed on the keyboard and puts it in a variable.

<!-- run: test keys="Ann\n7\n" -->
```basic
Dim nm As String, age As Integer
Input "Name"; nm
Input "Age"; age
Print nm; " will be "; age + 1; " next year"
```

```text
Name? Ann
Age? 7
Ann will be 8 next year
```

- `;` after the prompt adds `"? "`; `,` adds nothing.
- Into a number variable, the line is read as a whole number.
- With several variables, each gets its own line.

For one key without waiting, use `Inkey` (a code, 0 = none) or `Inkey$` (text, "" = none):

```basic
Dim k As String
Print "Y or N?"
Do : k = UCase$(Inkey$) : Loop Until k = "Y" Or k = "N"
Print "You said "; k
```
