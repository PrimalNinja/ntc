# 2.4 Variables and types

*2 Hello World*

`Dim` declares a variable and its type.

```basic
Dim count As Integer, big As Long
Dim nm As String, code As String * 4, line1 As String Max 80
count = 7 : big = 100000 : nm = "Ann" : code = "ab"
Print count; " "; big; " "; nm; " ["; code; "]"
```

```text
7 100000 Ann [ab  ]
```

| Type | Holds |
|---|---|
| `Integer` | whole numbers -32768 to 32767 |
| `Long` | whole numbers -2147483648 to 2147483647 |
| `Byte`, `Boolean` | 0-255, True (-1) / False (0) |
| `String` | up to 40 characters |
| `String Max n` | up to n characters (1-255) |
| `String * n` | exactly n characters, padded with spaces |

There are no fractions: NTC has no floating point.

`Const` gives a name to a fixed value; `Enum` a set of them; `Type` a record:

```basic
Const WIDTH = 40
Type Point
  x As Integer
  y As Integer
End Type
Dim p As Point
p.x = WIDTH \ 2 : p.y = 3
Print p.x; ","; p.y
```

```text
20,3
```

Arrays: `Dim a(10) As Integer` has 11 elements, 0 to 10. They don't make the program file
bigger: they go after it in memory and are cleared when it starts.
