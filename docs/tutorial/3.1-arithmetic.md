# 3.1 Arithmetic

*3 Calculations and maths*

NTC numbers are whole numbers. `+`, `-` and `*` work as you expect:

```basic
Print 7 + 3; ","; 7 - 10; ","; 6 * 7
Print 2 + 3 * 4; ","; (2 + 3) * 4
```

```text
10,-3,42
14,20
```

The order: `^` first, then the minus sign, then `*` `/` `\` `Mod`, then `+` `-`, then `&`
(joining text), then compares, then `Not`, `And`, `Or` / `Xor`. Brackets change it.

An `Integer` is 16 bits. Going past 32767 wraps round - there is no overflow error:

```basic
Print 32767 + 1
```

```text
-32768
```

For bigger numbers use `Long` ([3.3](3.3-long-numbers.md)).
