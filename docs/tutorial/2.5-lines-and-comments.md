# 2.5 Lines, comments and labels

*2 Hello World*

```basic
' a comment
Rem also a comment
Print "one" : Print "two"     ' : puts two statements on one line
Dim x As Integer
x = 1 + _
    2                         ' _ at the end joins the next line on
Print x
```

```text
one
two
3
```

- Case doesn't matter: `PRINT`, `print` and `Print` are the same.
- A line can start with a line number or a label (`name:`), for `GoTo` and `GoSub`
  (see [4.6](4.6-goto-and-gosub.md)).

```basic
10 Print "Hi"
20 GoTo done
30 Print "not printed"
done:
Print "end"
```

```text
Hi
end
```

VB5 / VB6 `.bas` and `.cls` files load as they are: their header lines (`VERSION`,
`Attribute ...`) are skipped.
