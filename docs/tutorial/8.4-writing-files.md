# 8.4 Writing files

*8 The FileSystem library*

`Open` a file `ForWrite` (an old one of that name is replaced), write, `Close` it - the last
part only reaches the disc at `Close`.

<!-- run: cpm -->
```basic
Dim h As Integer, r As Integer, i As Integer
h = FileSystem.Open("SQUARES.TXT", FileSystem.ForWrite)
For i = 1 To 3
  r = FileSystem.WriteLine(h, Str$(i) + " squared is" + Str$(i * i))
Next
r = FileSystem.WriteByte(h, 65)
r = FileSystem.Close(h)
h = FileSystem.Open("SQUARES.TXT", FileSystem.ForRead)
Do While Not FileSystem.Eof(h)
  Print FileSystem.ReadLine(h)
Loop
r = FileSystem.Close(h)
```

```text
 1 squared is 1
 2 squared is 4
 3 squared is 9
A
```

| Method | Does |
|---|---|
| `Open(name, FileSystem.ForWrite)` | a new, empty file |
| `WriteLine(h, text)` | the text and CR LF |
| `WriteByte(h, b)` | one byte |
| `Write(h, address, count)` | bytes from memory |

`Full` (-3) means the disc is full.
