# 7.1 System: what the machine is

*7 The System library*

`System` says what the machine is and what it can do. The same members are on every
platform; 0 / False means "not here".

| Member | cpc | cpcmin | cpcfw | cpm | test |
|---|---|---|---|---|---|
| `Platform` | "CPC" | "CPC minimal firmware" | "CPC firmware" | "CP/M" | "Test" |
| `CpuClock` (kHz) | 4000 | 4000 | 4000 | 0 | 4000 |
| `TicksPerSecond` | 300 | 300 | 300 | 0 | 300 |
| `FrameRate` | 50 | 50 | 50 | 0 | 0 |
| `HasHook` (`Interrupt`) | True | True | True | False | False |
| `HasScreen` | True | True | True | with `Option Terminal` | True |
| `MaxHandles` (files open) | 0 | 0 | 0 | 2 | 0 |

| Method | Does | Page |
|---|---|---|
| `Ticks()` | the tick count | [7.2](7.2-ticks-and-timing.md) |
| `HasCapability(name)` | can this platform do it? | [7.3](7.3-capabilities.md) |
| `CommandLine()` | what was typed after the program's name | [7.4](7.4-the-command-line.md) |
| `Command(name)` | run a ROM's command | [7.5](7.5-rom-commands.md) |

```basic
Print "Running on "; System.Platform
If System.TicksPerSecond = 0 Then Print "(no clock here)"
```

```text
Running on Test
```
