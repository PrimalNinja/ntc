# 3.3 Long numbers

*3 Calculations and maths*

A `Long` holds up to about 2 billion. A sum with a Long in it is worked out in 32 bits.

```basic
Dim big As Long
big = 300 * 300
Print big
big = CLng(300) * 300
Print big
big = 300 * 300&
Print big
```

```text
24464
90000
90000
```

The first one is wrong: `300 * 300` is two Integers, so it is worked out in 16 bits, and only
then put in the Long. Make one side Long: `CLng(300)`, or `300&` (the `&` makes a Long
literal). A literal over 65535 is a Long by itself.

Longs cost more time than Integers: use Integer unless the numbers get big.
