# 3.6 Text and numbers

*3 Calculations and maths*

Text has its own set of functions. A few that come up all the time:

```basic
Dim s As String
s = "Hello World"
Print Len(s); " "; Left$(s, 5); " "; Right$(s, 5); " "; Mid$(s, 3, 3)
Print UCase$(s); " "; InStr(s, "o"); " "; Replace(s, "o", "0")
Print "n=" & 5; " "; Str$(5); "|"; CStr(5); " "; Val("12abc") + 1
Print Format$(1234567, "#,##0"); " "; Format$(42, "0000")
```

```text
11 Hello World llo
HELLO WORLD 5 Hell0 W0rld
n=5  5|5 13
1,234,567 0042
```

- `&` (or `+`) joins text; a number is turned into text first.
- `Str$` puts a space in front of a positive number; `CStr` doesn't.
- `Val` reads a number from the start of the text.
- Others: `Trim$`, `LTrim$`, `RTrim$`, `LCase$`, `InStrRev`, `StrComp`, `Space$`, `String$`,
  `Chr$`, `Asc`, `StrReverse`, `Split`, `Join`, `Like`.

A `String` holds 40 characters; more is cut off. Declare `String Max 200` for longer text.
