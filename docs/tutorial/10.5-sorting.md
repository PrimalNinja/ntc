# 10.5 Sorting

*10 The List library*

`Sort(h, offset)` sorts the list by the word at *offset* (smallest first, as signed
Integers). Nodes with the same value keep their order.

```basic
Dim h As Long, n As Long, i As Integer, r As Integer
h = List.Create(4)
For i = 1 To 6
  n = List.Append(h)
  List.SetWord n, 0, i
  List.SetWord n, 2, (i * 37) Mod 10
Next
r = List.Sort(h, 2)
n = List.First(h)
Do While n <> 0
  Print List.GetWord(n, 2); "/"; List.GetWord(n, 0); " ";
  n = List.NextOf(n)
Loop
Print
r = List.Destroy(h)
```

```text
1/3 2/6 4/2 5/5 7/1 8/4
```

It is a radix sort: two passes over the list whatever the order, so the time grows in step with
the count. On a 6128: 500 nodes take about 0.4 seconds, 5,000 about 4.5 seconds. Each other
List call costs about 600 microseconds - most of the time in a BASIC loop over a list goes on
the calls. `bas/sorttime.bas` times it in turbo and normal mode.
