# 13.6 Pages: classes placed together

*13 Class overlays*

`Option Page Name = Class, Class ...` says which classes go into which page, in one place
(the main file). The classes listed are built together into one page file and loaded as one.
The two classes of [13.5](13.5-one-overlay-area.md), in one page:

<!-- file: A.cls -->
**A.cls**

```basic
Public Function Deep(ByVal x As Integer) As Integer
  Print "A";
  Deep = B.Mid(x) + 1
  Print " back in A"
End Function
Public Function Twice(ByVal x As Integer) As Integer
  Twice = x * 2
End Function
```

<!-- file: B.cls -->
**B.cls**

```basic
Public Function Mid(ByVal x As Integer) As Integer
  Print " B";
  Mid = A.Twice(x) + 10
  Print " back in B";
End Function
```

<!-- run: cpm -->
**Main.bas**

```basic
Option Page AB = A, B
Option Reserve &H4000, &H4000
Print A.Deep(3)
Print "B in the area: "; B.Loaded(); ", A: "; A.Loaded()
```

```text
A B back in B back in A
17
B in the area: -1, A: -1
```

One load (`MAIN.001`: the page AB), and the calls between A and B switch nothing - they are in the same page.

**A class in several pages is copied into each**, so the code in each page calls its own copy:

<!-- file: Level1.cls -->
**Level1.cls**

```basic
Public Function Play() As Integer
  Stars.Add
  Play = Maths.Square(3) + Stars.Count() * 100
End Function
```

<!-- file: Level2.cls -->
**Level2.cls**

```basic
Public Function Play() As Integer
  Stars.Add
  Play = Maths.Square(5) + Stars.Count() * 100
End Function
```

<!-- file: Maths.cls -->
**Maths.cls**

```basic
Public Function Square(ByVal n As Integer) As Integer
  Square = n * n
End Function
```

<!-- file: Stars.cls -->
**Stars.cls**

```basic
Private Paged n As Integer
Public Sub Add()
  n = n + 1
End Sub
Public Function Count() As Integer
  Count = n
End Function
```

<!-- run: cpcmin -->
**Main.bas**

```basic
Option Page Level1 = Level1, Maths, Stars
Option Page Level2 = Level2, Maths, Stars
Option RomEnable 7
Option Reserve &H4000, &H4000
Print Level1.Play(); " "; Level2.Play(); " "; Level1.Play()
Print "from main: "; Maths.Square(4); " "; Stars.Count()
```

```text
109 125 209
from main: 16 2
```

- A class in no page is in main RAM - put a class every page uses there.
- Calls from main (or another page) to a copied class go to its **home copy**: the first page
  that lists it, or `Option Home Stars = Level2`. `Stars.Count()` from main above is
  Level1's copy: 2.
- `Private Paged` variables are in each page, so **each copy has its own** (Stars counts per
  level: 1, 1, then 2 in Level1). Ordinary variables are in the program, shared by the copies.
  With one overlay area paged variables are ordinary variables, so the copies share them.
- The compiler lists each page's classes and sizes (the GUI's messages).
- `Option Class Overlay X` in a class is the short form of `Option Page X = ThisClass`.
- The page's name is for the source and the lists; its file is numbered (`MAIN.001` and
  `MAIN.002` here). `Option Page "FILE.EXT" = ...` picks the file yourself.
- A class in a page can also be an interrupt class (`Option Class Interrupt` in it): a driver
  with its own page and a `Tick` (RAM pages only).

The example `bas/pages/` has a title, two levels, credits and a class in main RAM.
