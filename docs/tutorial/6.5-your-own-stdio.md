# 6.5 Your own StdIO

*6 The StdIO library*

A project can have its own `StdIO.cls`. It replaces the platform's, and `Print`, `Input`,
`Cls` ... in the rest of the project call it. Inside it, the statements are the built-in
ones, so it can add to the normal console:

<!-- file: StdIO.cls -->
**StdIO.cls**

```basic
' every line printed is counted, and text goes out in capitals
Public Lines As Integer

Public Sub PutStr(ByVal s As String)
  Print UCase$(s);
End Sub

Public Sub NewLine()
  Print
  Lines = Lines + 1
End Sub
```

**Main.bas**

```basic
Print "hello"
Print "world"
Print StdIO.Lines
```

```text
HELLO
WORLD
2
```

Only the methods the program uses must be there; a missing one is a compile error naming it.
Copy `src/lib/<platform>/StdIO.cls` into a project to start from the platform's own. See
`bas/ownstdio/`.
