# 14.1 Interrupts and safe points

*14 Interrupt handlers*

The CPC interrupts the Z80 300 times a second. NTC's program runs with the stack pointer walking
through its code, so an interrupt can't be taken just anywhere. In **normal mode** (section
[5.3](5.3-turbo-and-normal.md)) the program lets interrupts in at **safe points**: every jump,
loop and call. In **turbo mode** they stay off.

What runs on interrupts:

| | What | Platforms |
|---|---|---|
| `Ticks` | counts them | cpc, cpcmin (cpcfw: the firmware's clock) |
| `Interrupt SubName` | runs a Sub after interrupts | cpc, cpcmin, cpcfw ([14.2](14.2-the-interrupt-statement.md)) |
| interrupt classes | a class's `Tick` at a set rate | cpc, cpcmin, cpcfw ([14.3](14.3-interrupt-classes.md)) |
| the keyboard, `Frame` | scanned / timed on them | all CPC platforms |

The interrupt itself only counts and marks things as due; your BASIC runs at the next safe
point. So it is ordinary BASIC, and can do anything - but it waits while a long statement runs.
`DoEvents` adds a safe point by hand.
