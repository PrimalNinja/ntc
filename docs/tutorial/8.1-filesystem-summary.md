# 8.1 FileSystem: files

*8 The FileSystem library*

Every platform has a `FileSystem` class with the same methods, so a program with files
compiles everywhere. What works depends on the platform:

| | cpc | cpcmin, cpcfw | cpm | test |
|---|---|---|---|---|
| `Load`, `Save` (whole files) | - | yes (disc or tape) | yes | - |
| `Open`, `ReadLine`, `WriteLine` ... (in order) | - | - | yes | - |
| `Seek` (random access) | - | - | yes | - |
| `Delete`, `Rename`, `Exists`, `Size` | - | - | yes | - |
| Devices, volumes | - | yes | yes | - |

Every method gives a number: 0 or more is a result, below 0 a status:

| Status | Value |
|---|---|
| `FileSystem.NotSupported` | -1: this platform can't |
| `NotFound`, `Full`, `BadName` | -2, -3, -4 |
| `NoHandle`, `BadHandle`, `EndOfFile` | -5, -6, -7 |
| `TooBig`, `Failed`, `AlreadyExists`, `BadMode` | -8, -9, -10, -11 |

`FileSystem.Capability(name)` asks about one thing: `LOAD`, `SAVE`, `SEQUENTIAL`,
`RANDOMACCESS`, `DELETE`, `RENAME`, `EXISTS`, `SIZE`, `MULTIPLE`, `DEVICES`, `VOLUMES` (True /
False), `MAXOPEN`, `RECORDSIZE`, `CPMVERSION` (numbers).

<!-- run: cpm -->
```basic
If FileSystem.Capability("RANDOMACCESS") Then Print "random access: yes"
Print "files open at once: "; FileSystem.Capability("MAXOPEN")
```

```text
random access: yes
files open at once: 2
```
