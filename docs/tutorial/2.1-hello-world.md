# 2.1 Hello World

*2 Hello World*

Start a **New project**. `Main.bas` holds:

```basic
Option Explicit

Print "Hello"
```

```text
Hello
```

Change it to say hello to the world, and wait for a key so the text stays on the screen:

```basic
Option Explicit

Print "Hello World"
Print "Press a key"
Do : Loop Until Inkey <> 0
```

- `Print` shows text.
- `Inkey` gives the key pressed, or 0 when there is none: the loop waits for one.
- `Option Explicit` makes the compiler check every variable is declared - keep it.

Build it (see [1.6](1.6-building-and-running.md)) and run it. On the CPC the program clears the
screen when it starts; on CP/M the text follows the `A>` prompt.
