# 9.5 Filling a page from a file

*9 The Memory library*

A page selected into the window is ordinary memory at `#4000-#7FFF`: `FileSystem.Load`
straight into it.

<!-- platform: cpcfw -->
```basic
Option RomEnable 7
Option Reserve &H4000, &H4000
Dim music As Integer, a As Integer, r As Integer
music = Memory.AllocPage(Memory.TypeUser)
If music = 0 Then Print "No music on this machine" : End
a = Memory.SelectPage(music)
r = FileSystem.Load("TUNE.BIN", Memory.WindowStart, Memory.WindowSize)
a = Memory.SelectPage(1)
If r < 0 Then Print "TUNE.BIN didn't load: "; r
```

Later, `SelectPage(music)` puts the tune back in the window for the player.

- `Memory.WindowStart` / `WindowSize` are constants (`&H4000`, `&H4000`), worked out when
  compiling.
- `AllocPage` gives 0 on a 64K machine when page 1 is taken: check it.
- Pages that the program loads code into are what overlay classes do for you (section 13).
