# 13.2 Building and shipping the files

*13 Class overlays*

One compile builds the program and every overlay file. Assembling writes them all:

| Platform | Program | Overlays |
|---|---|---|
| cpcmin, cpcfw | `NAME.BIN` | `LEVEL1.PAG` ... with an AMSDOS header (binary, loads at `#4000`) |
| cpm | `NAME.COM` | `LEVEL1.PAG` ... the plain bytes |

Put the `.PAG` files on the disc next to the program. On the CPC add `Option RomEnable 7`: after
`RUN"` AMSDOS is gone until the program starts it again, and the overlays would be looked for
on tape.

The disc images in `src/build/dsk/` have `OVERLAYS` with its `.PAG` files on the cpcmin, cpcfw
and cpm discs.

The program must end below `#4000`: overlays run at `#4000-#7FFF`. The assembler checks it. Each
overlay's code (with its paged variables) must fit in 16K.
