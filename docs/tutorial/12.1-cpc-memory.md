# 12.1 The CPC's memory

*12 Paging and overlays*

A Z80 sees 64K at a time: addresses `#0000-#FFFF`. A 6128 has 128K, and an expansion adds up to
4MB more. The CPC gets at the rest by switching 16K **pages** into one part of the 64K - the
gate array does it, one `Out` to port `&7F00`.

| Address | 64K CPC | What NTC uses it for |
|---|---|---|
| `#0000-#3FFF` | the program | the program starts at `#0040` |
| `#4000-#7FFF` | more program | the **window**: any page can be switched in here |
| `#8000-#BFFF` | the firmware's RAM and stack at the top | free up to `#A600` |
| `#C000-#FFFF` | the screen | the screen |

So with paging, a program stays below `#4000` (or above `#8000`) and the window is free for
pages: `Option Reserve &H4000, &H4000` checks that.

| Machine | Pages | |
|---|---|---|
| 464, 664 | 1 | main RAM's own `#4000` |
| 6128 | 5 | + its second 64K as pages 2-5 |
| + 512K expansion | 33 | |
| + 4MB expansion | 257 | WinAPE can have one |

CP/M runs the program from `#0100` up to the end of the TPA, and owns the second 64K itself,
so CP/M programs don't page.
