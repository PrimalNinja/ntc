# 1.5 Settings

*1 The IDE and projects*

The settings along the bottom of the IDE:

| Setting | What it does |
|---|---|
| **Platform** | the machine the program is built for: `cpc` (Amstrad CPC, no firmware), `cpcmin` (CPC, firmware kept for discs and ROMs), `cpcfw` (CPC, through the firmware), `cpm` (CP/M `.COM`), `test` (the test emulator) |
| **Start mode** | Normal (interrupts on) or Turbo - see [5.3](5.3-turbo-and-normal.md) |
| **Org** | where the program starts in memory. Empty = the platform's own (CPC `#0040`, CP/M `#0100`) |
| **Library** | which library routines go in: the ones used (normal), all, or none |
| **Source as comments** | each BASIC line goes into the assembler as a comment above its code |
| **Hide library in view** | shorter right pane: the library is still in Copy and Save .asm |
| **AMSDOS .BIN** | CPC platforms: the assembler writes the program as a `.BIN` file with an AMSDOS header, named after the project, ready for `RUN"` |

The platform and start mode are saved with the project. The platform changes what the
program can do - files, screen, interrupts. Each library section of this tutorial has a
table of what works where.
