LANGUAGES
English, Spanish and Russian: build/ (English), build/ES, build/RU, each with INTRO.NEX, INTRON.NEX and INTRO.DAT (copy the three to the SD card together).
Text: tools/lang/es.js, tools/lang/ru.js (same keys as tools/text.js). Build one: ZLANG=es node tools/assets.js, then ZLANG=es node tools/build.js both path/to/NTC/src.
Spanish capitals are drawn without accents (the font has 7 rows); N with a tilde, U with a diaeresis and the inverted ? and ! exist. Russian is all capitals.
The web version: game.htm?lang=es or ?lang=ru.
Screenshots of each language: screenshots/ES, screenshots/RU.
(After a language build run "node tools/assets.js" with no ZLANG again to put the English assets and src/Data.cls back.)
