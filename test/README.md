# NTC test harness (Python + Node scratch tools, not part of the compiler)

| File | What |
|---|---|
| `cli.js` | compile .bas / .cls / .js files to .asm from the command line (`node cli.js main.bas [more files] [--turbo] [--nocomments] [--platform=cpm] [--library=rom] [--flavour=js]`); `--vb` prints the VB5 text every file becomes (the JS flavour's translation) |
| `cpcrun.py` | compile, assemble (sjasmplus) and run on an emulated CPC: IM 1 interrupts every 13333 T, keyboard matrix, typed input, prints the screen text. The lower ROM is emulated only for the font (`font_standin.txt`, a public domain font standing in for Amstrad's). Typed text: `\n` = Return, `~` = one look at the keyboard that finds no key. `python3 cpcrun.py prog.bas 'typed\n' [more files] [--turbo]` |
| `ntcrun.py` | the same as `cpcrun.py` with `--platform=cpc\|cpcfw\|cpm\|test`: the host platforms run on a plain Z80 with the firmware jumpblock / BDOS / test ports handed to the harness, which keeps a text screen. cpm: `NTC_CPMVER=22` or `31` (default) is the version BDOS 12 gives - 31 runs the program in RAM configuration C2 as on a 6128 (Graphics reaches the screen, block 1, with C1); `NTC_GFXCHK=1` prints the number of screen bytes set at the end. cpcfw: characters written straight into screen memory in mode 2 (at SCR CHAR POSITION's addresses) show in the text screen too. `NTC_PROF=file`: a profile (PC, bank, SP at a random point of each 1/300 s, with the symbols, as JSON); `NTC_LIMIT=n`: stop after n 1/300 s chunks (default 30000); `NTC_PEEK=hex,hex`: 8 bytes at each address at the end. AMSDOS files: a headerless file reads as on the real ROMs (each #1A a soft end of file, reading goes on to the last 128 byte record, padded with #1A). `cyb_entry(name, length, long_name)`: a CyborgOS FILES.DIR / NAME.HDR entry. `NTC_UNIDOS=IDE,SD` (cpcfw): UniDOS stands in - paths `IDE:GAMES/NAME.EXT` in the CAS calls (each device a folder in the files folder, as A and B are), its Ctrl J BIOS command (KL FIND COMMAND #8A, RST 3 to it: 1 devices, 2 a device, 12 / 13 examine); `NTC_UNIDOS_NOEX=B`: drives it can't examine (AMSDOS's floppies); `NTC_FDC=a.dsk,b.dsk`: the disc controller (uPD765 at #FB7E / #FB7F, the motor #FA7E) with .DSK images in drives A and B (specify, recalibrate, seek, sense interrupt, read ID, read data; side 0), `make_dsk(path, files, 'data'|'system')` makes one |
| `zxnrun.py` | a ZX Spectrum Next for `ntcrun.py --platform=zxn`: the NEX file the assembly wrote, loaded as NextZXOS loads one; the MMU's 8K slots, NextRegs through ports #243B / #253B (#02 a soft reset ends the run, #07 the speed, #1E / #1F the raster line), the ULA and line interrupts (IM 1), the 8 x 5 keyboard (typed text as for the CPC, `{n}` = key n held: half row * 8 + bit, `{a+b}` keys held together - `{0+25*}` Caps Shift + 2 held until more is typed), the tilemap read back as text through the program's font. `NTC_ZXNREGS=1`: the NextRegs, slots and palette at the end. `NTC_TRACEZ=sp>c000` (or `sp<hex`, `pc>hex`, `pc=hex`): an instruction at a time, the last 300 (PC, SP, registers, the MMU) printed when the condition holds, `NTC_TRACEZ_SKIP=a-b,...` PC ranges left out. Note: the harness holds an interrupt until the Z80 takes it; the Next's INT is a pulse - a program with interrupts off while it passes loses it (ntc_plat_zxn.asm's handler and Frame wait recover the chain). `keys_zxn.bas` + `ref/keys_zxn.txt`: the Keys class on the Next; `inkey_zxn.bas` + `ref/inkey_zxn.txt`: Inkey's codes for the cursor keys (the CPC firmware's 240-243) and Delete |
| `cpcvdp.py` | `cpcrun.py`'s CPC with a model of an MSX card's ports (cpccard, cpc9990, the VDP / V9990 classes): a V9938 at &FF88 (registers, VRAM, the name table read back as text) and a V9990 at &FF60 (registers, VRAM, LMMV and LMMM; its bit map read back as text through `ntc_font6`, or saved as a PNG). `python3 cpcvdp.py prog.asm 'typed\n' [out.png]` (cli.js's output). The cartridge platforms were run in openMSX (`openmsx -machine C-BIOS_MSX2 -cart NAME.ROM [-ext gfx9000 \| -ext Sharp_HB-4000]`, `set videosource GFX9000` to see the V9990, `type` for keys, `screenshot -raw`) and MAME (`mame sc3000 -cart NAME.SC`, a Lua `-autoboot_script` pressing the SK-1100's matrix fields and taking a snapshot) |
| `mdbuild.py`, `mdrun.py`, `mdregress.sh` | the Sega Mega Drive (`md`): build a cartridge ROM (vasm), run it on the Genesis Plus GX libretro core (pads, pictures, plane A as text, a `--log` build's transcript), the self tests. `docs/md.md` |
| `m65build.py`, `m65run.py`, `m65regress.sh` | the MEGA65 (`m65`): build a PRG (vasm, 6502 oldstyle `-mega65`), run it on Xemu's xmega65 (joystick, keys, pictures, the console as text, a `--log` build's transcript), the self tests. `docs/m65.md` |
| `xemu/` | NTC's test driver for Xemu's xmega65: `ntctest.c` (commands over two pipes, one frame at a time) and `xemu-ntctest.patch` (hooks it in; Xemu commit 40dfef0). Not part of Xemu: `docs/m65.md` says how to build it |
| `stdio.bas`, `via/` + `ref/stdio.*.txt`, `ref/via.txt` | the StdIO / System platform classes on each platform, and a project with its own StdIO |
| `fs_cpm.bas`, `fs_fw.bas`, `fs_none.bas` + `ref/fs_*.txt` | the FileSystem class: CP/M (every method), CPC firmware (Load / Save), no files (test, cpc); the files go to `t/files` |
| `raw_t.bas` | FileSystem `ForReadRaw` (cpcfw, cpcmin): a headerless RAW.COM with #1A bytes read to its last record, and `Eof` reading ahead |
| `realcpc.c`, `realcpcbin.sh` | a CPC 6128 with the real Amstrad ROMs and AMSDOS (the floooh/chips emulator, built with gcc): boots BASIC, inserts a .DSK, types, takes screenshots, counts fetches of addresses (with the lower ROM on or off); `XROM=file [XSLOT=n]` fits a ROM image (e.g. `build/rom/NTCFW.ROM`, slot 6), `XROM2=file [XSLOT2=n]` ... `XROM8` more (a keyword ROM set; slots 5, 4 ...). For what the harness can't show - how the real firmware calls the program (cpcfw interrupts, Graphics under the firmware). Needs the chips headers and the ROM images (github.com/floooh/chips, chips-test) ; script `type` takes `\c1` ... `\c8` and `\ce` for Control + 1-8 / ESC; `PROF=file`: a profile - every clock tick counted against its instruction's address, for main RAM, a bank (setting C2), the lower and the upper ROM (`profon` in the script restarts it) |
| `genromdisc.js` | `node genromdisc.js outdir FILE ...`: a ROMDISC (`NTCDISC.ROM`, `NTCDISC2.ROM` ...) from the files, through `ntcRomDisc`; the harness fits it in slots 10, 11 ... with `NTC_ROMDISC=outdir/NTCDISC.ROM` |
| `genrom.js` | `node genrom.js cpc\|cpcmin\|cpcfw`: builds that platform's keyword library ROM (`build/rom/NTCCPC`, `NTCMIN`, `NTCFW` `.ASM` / `.ROM`) and appends new entries to its registry `asm/ntc_rom_<platform>.txt` (then run `gen.js`); a set of more than one ROM (`NTCMIN2.ROM` ...) when it doesn't fit. `--cap=bytes` (a smaller ROM: forces a split), `--place=section:rom,...` (by hand), `--out=dir` (elsewhere, registry file left alone) |
| `genbuild.js` | writes `build/<platform>/NAME.ASM` (every program in `bas/` for every platform) for `build/build.bat` |
| `guitest6.py` | every example on every platform in the GUI |
| `argfn/` | function results as arguments (`Show 1, 2, F(3), F(4) ...`: each call's result kept before the next call - once all got the last one's) |
| `s3d/mkcut.py`, `s3d/make.js` | the AUCKLAND test: `mkcut.py out.txt.gz` writes a made-up 2 km town as an OSM Cut file (tools/osmcut's text); `node make.js s3dmake.html cut.txt.gz OUT.DAT [NAME]` runs tools/s3dmake's converter on it; regress.sh then flies AUCKLAND.BIN through it (`--ram=4160`, `NTC_AMSDOS=1`) |
| harness: `NTC_AMSDOS=1`, `NTC_SHOT=file`, `NTC_DUMP=file`, `shot.py` | ntcrun.py: AMSDOS on from the start (a program RUN from a disc: its files on A, not tape); at the end the CRTC's R12, main RAM #4000-#7FFF and the screen at #C000 written to a file (`python3 shot.py file out.png`: both screens as mode 1 pictures, side by side); the 64K the Z80 sees written to a file |
| `regress.sh` | every test program in both modes on the CPC, then on the test / cpcfw / cpm platforms, the platform classes, + ES5 check of the JS. Ends with ALL PASS |
| `gen.js` | rebuilds `js/ntc_lib.js` (from `asm/*.asm`) and `js/ntc_examples.js` (from `bas/`) - run after changing the library or examples |
| `guitest*.py` | Playwright tests of `ntc.html` (examples compile with no errors, procedure list, .vbp open) |
| `for.bas gs.bas gs2.bas scr0.bas scr2.bas` + `ref/` | FOR / GOSUB / screen tests with expected output |
| `out/` | the builds of those small test programs (and hook, diag1, diag2, vbprint, cmptext, tiny, wrap), a folder for each platform and mode - `out/cpc`, `out/cpc_turbo`, `out/cpcfw_rom` ...: their .asm, .bin and .sym side by side to compare (regress.sh writes them) |
| `vbp/` | a .vbp with its files for `guitest4.py` |
| `loc/` + `ref/loc_*.txt` | Locomotive BASIC flavour tests: a type-in style listing (with its warnings) on every platform, and its translation |
| `jsf/` + `ref/jsf_*.txt` | JS flavour tests: a JS program, a VB main with a JS class and module, a JS main with a JS class (#asm, Turbo), the translation, the refused forms |
| `cpm/cpmt.asm`, `cpm/rdt.asm` | CyborgOS test programs in plain Z80 (cpm, `.CYB`): its CP/M calls (default FCBs, TAB, the BIOS, BDOS 1, 10, 12, 17, 18, 24, 35, 36); random access on a RAM disc. Kept out of this folder: `regress.sh` ends by deleting `*.asm` here |

Needs: python3 with `pip install z80` (Z80Machine), sjasmplus on the PATH (or `SJASMPLUS=/path/to/sjasmplus`),
node with `npm install` here (acorn for the ES5 check), Playwright + Chromium for the GUI tests.
